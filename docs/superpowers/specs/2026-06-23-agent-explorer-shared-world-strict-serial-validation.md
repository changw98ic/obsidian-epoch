# 黑曜纪元 Agent 探索者共享大世界严格串行 100 轮对抗验证

验证对象：`docs/superpowers/specs/2026-06-23-agent-explorer-shared-world-spec.md`

这份文件是第三版验证。它不把 100 轮当成一次性清单，而按串行方式记录：每一轮先攻击“上一轮修订后的当前 spec”，若发现缺口，立即给出修订编号 `S###`，并在主 spec 第 31 节落地。后续轮次默认以前序 `S###` 已生效为基线继续攻击。

## Round 001-020：新手体验、参与感和失败回流

### Round 001 - UX / 30 秒首屏

- 当前基线：spec 第 30.1 已要求首局只展示推荐 agent、推荐委托、Key 安全提示、成本和开始按钮。
- 攻击：真实首屏如果仍同时显示世界地图、声望、设定集入口和 agent 详情，新用户会在 30 秒内迷失。
- 判定：FAIL。第 30.1 限制首局内容，但没有规定首屏信息预算和可见元素数量。
- 立即处置：S001。首屏最多 5 个主要信息块，世界图谱、设定账本、声望树默认折叠到“稍后查看”。

### Round 002 - UX / 首局不知道该选什么

- 当前基线：S001 限制了首屏，但用户仍可能卡在“推荐委托”是否可信。
- 攻击：用户不理解腐林、湿谷、城市管道区别，停在选择界面。
- 判定：FAIL。需要无选择首局。
- 立即处置：S002。首局默认走单一“档案馆推荐委托”，用户只选择风险偏好：谨慎、均衡、冒险。

### Round 003 - UX / API Key 恐惧

- 当前基线：S002 简化首局，但 Key 输入仍是最大心理阻力。
- 攻击：用户看到“输入 API Key”直接关闭，担心被偷。
- 判定：FAIL。已有不上传承诺，但缺少可感知证明。
- 立即处置：S003。Key 输入区必须有“本地调用示意”和“网络请求不含 Key”的可检查说明；提供演示模式，不输入 Key 也能看一次假数据流程。

### Round 004 - UX / 演示模式污染真实奖励

- 当前基线：S003 增加演示模式。
- 攻击：用户用演示模式刷战报、奖励和设定。
- 判定：FAIL。演示模式必须完全隔离。
- 立即处置：S004。演示模式只生成本地样例，不可上传、不可结算、不可获得声望，只用于理解流程。

### Round 005 - UX / 用户不信任 agent 决策

- 当前基线：第 30.3 要求关键行动解释。
- 攻击：解释只有“我认为风险可控”，用户仍觉得黑箱。
- 判定：FAIL。解释必须结构化。
- 立即处置：S005。每个关键行动解释固定为：触发线索、可选方案、选择原因、放弃原因、风险、预计收益。

### Round 006 - UX / 解释太长造成疲劳

- 当前基线：S005 增强解释。
- 攻击：每个事件都展开六段解释，用户读不动。
- 判定：FAIL。解释需要渐进披露。
- 立即处置：S006。默认只显示一句“行动理由”，详细解释折叠；高危授权自动展开完整解释。

### Round 007 - UX / 用户想干预但找不到入口

- 当前基线：第 30.4 允许暂停、插入指令、手动接管。
- 攻击：如果这些功能藏在菜单里，用户仍觉得旁观。
- 判定：FAIL。介入入口必须常驻。
- 立即处置：S007。探索界面固定提供三个轻量按钮：暂停、追加指令、接管本轮；高危时替换为授权面板。

### Round 008 - UX / 用户频繁接管破坏 agent 玩法

- 当前基线：S007 暴露接管按钮。
- 攻击：用户每轮都接管，系统退化成普通跑团。
- 判定：FAIL。接管要有额度和叙事解释。
- 立即处置：S008。手动接管消耗“委托干预次数”；MVP 每局默认 1 次，高声望可增加，但会降低 agent 自主评价。

### Round 009 - UX / 高危授权过载

- 当前基线：第 30.4 要求高危授权二级确认。
- 攻击：冒险 agent 连续提出旧神交易、牺牲外物、进入裂隙，用户被授权弹窗轰炸。
- 判定：FAIL。高危请求需要节流和合并。
- 立即处置：S009。每局高危请求有上限；同类高危请求合并为一次“风险包”，用户可以授权、拒绝或改风险策略。

### Round 010 - UX / 低刺激模式被隐藏

- 当前基线：第 30.7 要求低刺激模式。
- 攻击：用户只有在不适后才发现设置。
- 判定：FAIL。可访问性必须前置。
- 立即处置：S010。首次进入和每个高刺激委托前都显示低刺激开关，且用户选择持久保存到本地档案。

### Round 011 - UX / 首局失败导致流失

- 当前基线：第 30.5 要求失败后回流资产。
- 攻击：首局 agent 死亡，即使有遗物，用户也觉得惩罚太重。
- 判定：FAIL。首局需要保护。
- 立即处置：S011。首局默认不永久死亡；最坏结局是“重伤封存/失踪待找回”，死亡机制从第二局或高风险委托开始。

### Round 012 - UX / 失败保底被刷

- 当前基线：S011 保护首局。
- 攻击：用户反复新身份跑首局，获取失败保底和线索。
- 判定：FAIL。首局保护与收益必须分离。
- 立即处置：S012。首局保护只保 agent，不给可迁移声望、源流、外物；演示/首局产物必须通过后续真实委托证实才有世界影响。

### Round 013 - UX / 回访摘要不够行动化

- 当前基线：第 30.6 要求三行回访摘要。
- 攻击：摘要告诉用户“带回 2 条候选设定”，但用户不知道该点哪里。
- 判定：FAIL。摘要要有单一下一步。
- 立即处置：S013。回访摘要必须带一个主按钮：审档、修正、接续、找回或领取；不能只汇报状态。

### Round 014 - UX / 结算信息太多

- 当前基线：第 30.2、30.6 强化结算和回访。
- 攻击：评分、设定、地图、声望、外物、下一局同时出现，用户读不完。
- 判定：FAIL。结算需要阶段门。
- 立即处置：S014。结算分四屏：结局、评分、掉落、下一步；每屏只保留一个主动作。

### Round 015 - UX / 用户不知道“设定主张”是什么

- 当前基线：spec 大量使用“设定主张”。
- 攻击：新用户听不懂主张、证据、审档等术语。
- 判定：FAIL。前台术语仍过硬。
- 立即处置：S015。前台把“设定主张”显示为“可入档发现”；高级详情里再显示 claim/schema。

### Round 016 - UX / 用户不关心世界图谱

- 当前基线：产品核心之一是地图点亮。
- 攻击：用户只看 agent，不点地图，世界影响感弱。
- 判定：FAIL。地图反馈要嵌入结算。
- 立即处置：S016。结算掉落屏必须显示“本局影响了哪个地点/阵营/争议”，用小地图切片而不是让用户自己打开大图。

### Round 017 - UX / 长期目标抽象

- 当前基线：第 30.6 要求三个近期目标和长期目标。
- 攻击：长期目标写成“提升档案信用”，没有想象力。
- 判定：FAIL。目标要世界内化。
- 立即处置：S017。长期目标以世界内称号/权限呈现，如“成为腐林证实者 II”“解锁云脑族断线委托”。

### Round 018 - UX / Agent 档案像后台表格

- 当前基线：agent 档案有字段和收藏。
- 攻击：档案页若是 JSON 式属性表，用户无情感绑定。
- 判定：FAIL。档案需要叙事年表。
- 立即处置：S018。agent 档案首页展示经历年表、最近伤痕、关系变化和一句 agent 自述；结构化字段放二级页。

### Round 019 - UX / 分享卡造成误解

- 当前基线：第 30.7 允许分享卡。
- 攻击：外部观众看到分享卡，以为传闻是正史。
- 判定：FAIL。分享卡必须带状态和来源。
- 立即处置：S019。分享卡强制显示设定层级、来源战报、是否已证实，传闻和争议不得用“官方确认”式视觉。

### Round 020 - UX / 第一阶段仍过大

- 当前基线：前 19 轮新增大量 UX 规则。
- 攻击：MVP 范围膨胀，第一版做不出来。
- 判定：FAIL。必须拆 MVP 必做与后续增强。
- 立即处置：S020。第 31 节标注每条修订的 MVP/后续级别；MVP 只保首局压缩、Key 安全、基础解释、一次干预、四屏结算和单一下一步。

## Round 021-040：世界观一致性、秘密控制和设定密度

### Round 021 - WORLD / 前台层级仍可能误读

- 当前基线：S019 要求分享卡显示层级。
- 攻击：应用内设定卡如果只靠颜色区分，用户截图后仍可能把传闻当正史。
- 判定：FAIL。层级必须文本化。
- 立即处置：S021。所有设定卡标题区强制文字标签：正史、共享、证实、传闻、争议、封存；颜色只能辅助。

### Round 022 - WORLD / 首局推荐委托暴露秘密

- 当前基线：S002 使用推荐委托。
- 攻击：推荐委托为了吸引人，直接提到深层秘密，如“神尸矿区真正源头”。
- 判定：FAIL。推荐委托需要秘密安全等级。
- 立即处置：S022。每个委托带 `secretExposureTier`，首局只能使用 T0/T1 公开或低阶传闻。

### Round 023 - WORLD / 多轮低阶线索拼出真相

- 当前基线：S022 限制首局秘密等级。
- 攻击：用户连续跑 20 个 T1 传闻，拼出 T4 真相。
- 判定：FAIL。需要累计揭露预算。
- 立即处置：S023。秘密线索按主题维护揭露预算；同一探索者、agent、地点、章节的线索累计超过阈值后转为模糊提示或章节锁。

### Round 024 - WORLD / 设定密度吞掉地点气质

- 当前基线：第 30.13 有章节入口预算。
- 攻击：腐林出现太多树洞、盐痕、回声、低语，地点失去原本主调。
- 判定：FAIL。预算要按母题分配。
- 立即处置：S024。每个地点维护母题配额：生态、生物、阵营、异常、资源、人物；同母题过密时自动聚合或降权。

### Round 025 - WORLD / 现实梗绕过气质审核

- 当前基线：第 30.8 禁轻浮现实梗。
- 攻击：用户把现实梗换成谐音或隐喻，仍破坏世界气质。
- 判定：FAIL。仅关键词不够。
- 立即处置：S025。气质审核加入“现实映射/互联网梗/戏仿痕迹”评估；疑似内容只允许个人封存，不进共享设定。

### Round 026 - WORLD / 自创组织通过地点绑定变强

- 当前基线：第 16、30.12 限制自创阵营。
- 攻击：玩家不叫阵营，叫“地方互助会”，实际拥有据点、武装、技能和外交。
- 判定：FAIL。组织强度不能只看名称。
- 立即处置：S026。组织类 claim 按影响力评分：成员规模、资源、武装、领地、外交、超凡能力；超过阈值自动进入阵营候选审档。

### Round 027 - WORLD / 技能家族绕开上限

- 当前基线：S024 和第 30.9 有技能家族上限。
- 攻击：用户换名字创建相同功能技能，绕开“蚀雾回声术”家族限制。
- 判定：FAIL。技能家族要按效果聚类。
- 立即处置：S027。能力类 claim 按效果、成本、媒介、地点、触发条件聚类，不只按名称归族。

### Round 028 - WORLD / 生物行为与威胁等级不匹配

- 当前基线：第 30.9 检查生物字段。
- 攻击：E 级生物在战报中造成世界级后果，但文本写得有代价。
- 判定：FAIL。威胁等级要约束影响范围。
- 立即处置：S028。生物行为 claim 的影响范围不得超过 threat/rank_role 对应上限；超出时必须解释为外部污染、群体事件或更高实体介入。

### Round 029 - WORLD / 时间线拥挤绕过

- 当前基线：第 30.10 维护时间线拥挤度。
- 攻击：用户把时间写成“裂灾后十七年左右”，避免具体冲突。
- 判定：FAIL。模糊时间也要占用区间。
- 立即处置：S029。模糊时间映射为时间区间并占用拥挤度；不能用模糊时间逃避时间线校验。

### Round 030 - WORLD / 地图跨区影响绕过

- 当前基线：第 30.10 要求跨区域机制。
- 攻击：用户写“梦中影响”，把任意两地连接起来。
- 判定：FAIL。梦境连接也需要许可。
- 立即处置：S030。跨区机制分等级；梦境、裂隙、旧神低语属于高阶连接，需要章节许可或已有路线支持。

### Round 031 - WORLD / 传闻池变垃圾桶

- 当前基线：低权重主张可进传闻池。
- 攻击：大量低质内容都被“传闻”吸收，用户浏览体验变差。
- 判定：FAIL。传闻也要门槛。
- 立即处置：S031。传闻池要求最低锚点完整性和世界气质评分；低于门槛只个人封存。

### Round 032 - WORLD / 争议悬案过度游戏化

- 当前基线：冲突变公共悬案。
- 攻击：为了制造玩法，系统把本该退回的烂设定也包装成悬案。
- 判定：FAIL。争议需要价值门槛。
- 立即处置：S032。进入争议档案必须同时满足：双方都有有效证据、冲突可被后续探索检验、不是核心正史硬冲突。

### Round 033 - WORLD / 正史升级路径不清

- 当前基线：普通设定不能直接成正史。
- 攻击：高质量共享设定长期没有进入正史路径，贡献者失望。
- 判定：FAIL。要有主理人采纳流程。
- 立即处置：S033。新增“正史候选”路径：铭刻设定经章节复审、主理人批准、迁移说明后才能进入正史。

### Round 034 - WORLD / 正史采纳伤害原作者权益

- 当前基线：S033 允许正史采纳。
- 攻击：平台改写设定进正史，原作者觉得被吞。
- 判定：FAIL。采纳需要署名与改写边界。
- 立即处置：S034。正史采纳保留源流署名；可改写文字和边界，但必须保留“源出战报/探索者/agent”记录。

### Round 035 - WORLD / 世界版本迁移太抽象

- 当前基线：第 30.25 要影响报告。
- 攻击：版本升级后用户不知道自己的哪些设定受影响。
- 判定：FAIL。影响报告要用户级摘要。
- 立即处置：S035。世界版本迁移生成个人影响摘要：被保留、被降级、需补证、被采纳、被封存的设定列表。

### Round 036 - WORLD / 官方世界资料本身有冲突

- 当前基线：系统假设正史是稳定真源。
- 攻击：现有 Obsidian 资料中也可能存在旧版矛盾或低置信度自动推断。
- 判定：FAIL。正史源也要置信度。
- 立即处置：S036。官方资料进入上下文时带 `sourceAuthority`：core、official、derived、low-confidence；derived/low-confidence 不可作为硬反驳依据。

### Round 037 - WORLD / 低置信官方推断压制用户好设定

- 当前基线：S036 标出 sourceAuthority。
- 攻击：用户高质量设定被一个自动推断地点坐标否掉。
- 判定：FAIL。低置信官方数据不能压制高质量用户证据。
- 立即处置：S037。冲突裁定按权威等级、证据质量、来源时间共同判断；低置信派生数据触发复核而非直接驳回用户主张。

### Round 038 - WORLD / 主线章节被用户预档污染

- 当前基线：章节未开放区域可低权重预档。
- 攻击：预档数量太多，章节开放时主线被预设裹挟。
- 判定：FAIL。预档需隔离。
- 立即处置：S038。未开放章节预档不进入公开图谱，不参与源流收益，只作为主理人可选素材池。

### Round 039 - WORLD / 地点母题被热门奖励扭曲

- 当前基线：S024 有母题配额。
- 攻击：某母题奖励高，玩家集中写它，导致地点气质偏斜。
- 判定：FAIL。奖励需要反向调节。
- 立即处置：S039。地点母题奖励随过密程度下降，稀缺但合规母题获得探索加成。

### Round 040 - WORLD / 世界观验证范围继续膨胀

- 当前基线：S021-S039 增加很多守门规则。
- 攻击：MVP 世界观守门变得过重，第一版无法审档。
- 判定：FAIL。需要 MVP 守门最小集。
- 立即处置：S040。MVP 只强制：层级标签、秘密等级、锚点完整性、气质守门、重复/冲突、传闻最低门槛；其余作为二阶段增强。

## Round 041-060：安全、隐私、作弊和奖励经济

### Round 041 - SAFETY / Key 出现在浏览器崩溃日志

- 当前基线：S003 有 Key 安全说明，第 29.7 禁止日志记录。
- 攻击：前端错误边界把输入框状态上传到 error reporting。
- 判定：FAIL。必须把 Key 输入组件隔离出错误上报。
- 立即处置：S041。Key 组件不纳入全局状态、错误上报、analytics；任何 error payload 发送前做 Key 模式脱敏扫描。

### Round 042 - SAFETY / 用户复制粘贴 Key 到委托文本

- 当前基线：S041 防组件泄露。

## Round 061-080：后端一致性、审档成本和 agent 行为

### Round 061 - BACKEND / runTicket 并发使用
