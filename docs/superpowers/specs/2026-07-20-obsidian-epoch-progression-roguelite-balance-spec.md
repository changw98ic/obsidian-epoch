> 状态：Draft for simulation  
> 日期：2026-07-20  
> Spec 版本：1.0.0  
> 数值版本：2026.07.20-v1  
> 对应平衡数据：[balance catalog v1](./2026-07-20-obsidian-epoch-balance-catalog-v1.json)  
> 对应材料与配方数据：[materials crafting catalog v1](./2026-07-20-obsidian-epoch-materials-crafting-catalog-v1.json)

## 0. 执行摘要

这份 Spec 解决五个核心问题：

- 角色为什么成长，以及成长证据从哪里来。
- 七套力量体系如何共享裁定框架，同时保持来源、资源、代价和风险独立。
- 天赋、修行、技法、技能树、局内赐福和轮回谱系如何各司其职。
- 如何衡量角色面对某一场战斗的准备度，而不制造一个能解释一切的全局战斗力。
- 如何让 8 至 12 节点的 Roguelite 单局、30 局长期成长、真实世界经济和 RAG 记忆同时成立。

本设计的核心结论如下：

1. 属性不再按低、中、高强度对局自动增加。属性只由具体行动证据、训练时间、挑战适配、恢复状态和重复衰减共同决定。
2. 游戏不提供全局战斗力。角色拥有十维战斗准备向量，只有面对具体遭遇时才计算一次性的适配度。
3. 局外成长以横向能力为主，包括带入格、部署容量、候选池定向、保险和回响槽，不以永久伤害倍率为主。
4. 局内构筑必须归零。保留的是方法熟悉度、可验证知识、伤病、债务、污染、关系和已合法提取的资产。
5. 世界事件账本是唯一事实源。SQLite、RAG、角色面板、结果页和模拟器都只是可重建投影。
6. 所有任务奖励必须来自合同托管、组织预算、场景库存、世界储备、合法回收或经过审计的铸造事件。
7. 数值目录是实现阶段唯一平衡参数来源。本 Spec 解释原因，不允许业务代码复制一份倍率。

## 1. 产品北极星

### 1.1 北极星

玩家应感受到自己在一个持续运行的世界里培养具体身份，而不是在菜单里叠一条战斗力数字。每次任务都应同时产生五类可感知结果：

| 结果层 | 玩家感知 | 权威记录 |
|---|---|---|
| 世界结果 | 库存、价格、势力、路线、见证者发生变化 | world 账本 |
| 身份结果 | 技法更熟、受伤、负债、关系改变 | identity 账本 |
| 局内结果 | 形成一套本局构筑并面对撤离决策 | run 账本 |
| 谱系结果 | 有限回响、保险、带入选择变多 | lineage 账本 |
| 记忆结果 | 少量重要经历可被后续可靠召回 | solidified RAG 投影 |

### 1.2 非目标

- 不做一个跨体系通用的法力值。
- 不做一个跨场景通用的总战斗力。
- 不让稀有度直接成为线性强度等级。
- 不让每局结束固定增加一项属性。
- 不让局外成长消除局内构筑、准备和风险选择。
- 不让 RAG、LLM 文本或 UI 投影直接修改余额、奖励、控制权或死亡状态。
- 不在首个垂直切片同时铺开七体系全部内容。
- 不把任务失败自动等同于角色死亡。

## 3. 数据优先与权威模型

### 3.1 两份文档的职责

| 文档 | 职责 | 是否可被运行时直接读取 |
|---|---|---|
| balance catalog v1 | 参数、公式、阈值、概率、槽位、验收目标 | 是 |
| 本 Spec | 概念、边界、理由、流程、迁移和验收解释 | 否 |

任何数字变更必须先修改 balance catalog，再更新版本与变更说明。代码中只允许存在字段名、算法实现和安全硬上限，不允许复制平衡值。

### 3.2 三层生命周期、四个账本命名空间

“三层”描述生命周期，“四个账本”描述物理命名空间：

| 生命周期 | 账本 | 保留周期 | 代表数据 |
|---|---|---|---|
| 永久层 | world | 永不因玩家重开而重置 | 地区、势力、组织账户、库存、路线、历史 |
| 永久层 | lineage | 跨身份保留 | 代号、回响槽、谱系印记、保险资格 |
| 身份层 | identity | 服务端确认真实死亡时结算 | 属性、修行、技法、天赋、伤病、关系、债务 |
| 单局层 | run | 对局结算时清空 | 路线、赐福、临时构筑、局内压力和待确认战利品 |

这四个账本不是四套数据库。它们都必须表现为同一 canonical event ledger 中的事件命名空间，投影可以分表，但不能成为第二事实源。

### 3.3 结算收据

每次属性增长、技法练习、技能解锁、任务结算、撤离、死亡和记忆固化都必须生成可重放收据。收据至少包含：

| 字段 | 目的 |
|---|---|
| eventId | 幂等与审计 |
| actorId / identityId | 区分账号、谱系和当世身份 |
| worldVersion / contentVersion | 解释当时世界与内容 |
| rulesetVersion / balanceVersion | 解释当时公式 |
| seed / seedHash | 重放随机选择 |
| catalogHash | 证明使用的数值目录 |
| sourceEventIds | 追溯训练、奖励和记忆来源 |
| beforeHash / afterHash | 检查状态跃迁 |
| occurredAtWorldMinute | 接入持续世界时间 |

## 4. 角色数值本体

### 4.1 角色面板不是一张属性表

完整角色面板分为六层：

| 层 | 内容 | 变化速度 |
|---|---|---|
| 基础承载 | 力量、敏捷、体魄、智力、意志、灵性 | 慢 |
| 修行结构 | 主体系、传承、分支、功能阶段、领域 | 中慢 |
| 方法能力 | 技法熟练度与掌握、控制、稳定、应变 | 中 |
| 装备与准备 | 装备、消耗品、情报、场景准备 | 中快 |
| 当前状态 | 体能、专注、伤病、污染、债务、暴露 | 快 |
| 遭遇投影 | 十维准备向量与具体遭遇适配度 | 即时 |

基础属性永远不能直接回答“谁一定赢”。它只提供承载上限和默认投影。

### 4.2 六项基础属性

| 属性 | 主要表达 | 不应独占的能力 |
|---|---|---|
| 力量 | 施力、负载、冲击、抓握 | 所有伤害 |
| 敏捷 | 反应、平衡、运动精度、闪避 | 所有命中 |
| 体魄 | 耐力、恢复、疼痛和毒素承受 | 所有防御 |
| 智力 | 分析、工程、规划、学习 | 所有法术 |
| 意志 | 纪律、恐惧抵抗、专注和主体连续性 | 所有精神能力 |
| 灵性 | 共鸣、仪式、灵魂感知和领域接触 | 所有超凡能力 |

创建基准是总预算 180，每项 20 至 40。种族和出身修正分别限制在正负 8 与正负 4，并各自零和，避免某个出身凭空获得更高总预算。

### 4.3 属性增长必须有真实证据

旧逻辑“低强度加智力、中强度加意志、高强度加体魄”必须废弃。对局强度只能说明风险，不能说明角色练习了什么。

属性经验公式为：

| 项 | 取值 |
|---|---|
| 基础经验 | 每个合格行动 4 |
| 相关度 | 0 至 1 |
| 挑战适配 | 琐碎 0.2、偏低 0.6、匹配 1.0、困难 1.2、极端 1.1 |
| 执行质量 | 0.5 至 1.2 |
| 恢复状态 | 0.5 至 1.0 |
| 重复新颖度 | 1.0、0.75、0.50、0.25 |

属性经验 = 基础经验 × 相关度 × 挑战适配 × 执行质量 × 恢复状态 × 新颖度。

单局每项属性最多获得 10 点证据经验，六项合计最多 24 点。刻意训练每天可获得 18 至 30 点，但必须消耗世界时间、导师或设施、食物、恢复与对应材料。

属性从当前值 x 增加 1 点所需经验：

经验需求 = round(20 + 1.5 × x + 6 × max(0, x - 55))

该曲线意味着 30 点附近仍可稳定训练，55 点后明显变慢，避免任务刷取造成线性膨胀。

### 4.4 属性软上限

| 功能阶段 | 属性软上限 |
|---:|---:|
| 1 | 40 |
| 2 | 50 |
| 3 | 60 |
| 4 | 70 |
| 5 | 80 |
| 6 | 90 |

软上限不是硬锁。超出当前承载的增长需要更高成本，并更容易表现为伤病、失稳或资源浪费。展示有效值采用分段收益：

| 原始区间 | 有效收益 |
|---|---|
| 0 至 55 | 100% |
| 55 至 75 | 60% |
| 75 以上 | 30% |

## 5. 七套力量体系与六个共享领域

### 5.1 体系适配器

功能阶段只统一“能做多复杂的事”，不统一力量来源。

| 体系 | 本地资源 | 主要代价 | 首版波动倍率 |
|---|---|---|---:|
| 裂灾血脉与本相 | 载体稳定 | 载体失衡、环境依赖、身份磨损 | 1.10 |
| 东方修行 | 气与经脉承载 | 经脉损伤、心魔、因果债 | 1.00 |
| 西方奥术 | 预备术式与奥术充能 | 反噬、契约债、记忆割让 | 1.05 |
| 原初神契 | 契约信用与真名完整 | 失名、誓约反噬、神罚 | 1.00 |
| 旧日与星外共鸣 | 共鸣与主体完整 | 污染、异化、主体性下降 | 1.25 |
| 理性工程 | 能源、数据、材料、权限 | 故障、权限冻结、数据污染 | 0.85 |
| 赛博工业 | 能量、带宽、维护、产权 | 成瘾、债务、产权丧失、人格碎裂 | 0.95 |

这些倍率只用于同风险级别的初始仿真，不代表某体系强弱。内容必须通过可用性、资源链、环境和反制关系完成最终平衡。

### 5.2 共享领域

| 领域 | 建议最低功能阶段 | 压力倍率 |
|---|---:|---:|
| 灵魂与死亡 | 2 | 1.10 |
| 梦境与心灵 | 1 | 1.00 |
| 命运与时间 | 4 | 1.20 |
| 星空、空间与量子 | 4 | 1.15 |
| 血肉、血脉与异化 | 1 | 0.95 |
| 生态、元素与环境 | 1 | 1.00 |

领域不是技能学校。它表示不同体系作用于同一现实问题时的交叉裁定面。

### 5.3 主辅体系

| 关系 | 效率上限 | 节点税 | 是否允许成为常驻构筑 |
|---|---:|---:|---|
| 共鸣 | 100% | 0 | 是 |
| 可转译 | 60% | 1 | 是 |
| 冲突 | 30% | 2 | 否，只允许临时技法 |
| 禁忌 | 0% | 不适用 | 否 |

每个身份只有一个主体系、一个主传承和一个主分支。辅体系最多两个，但第二辅体系主要服务叙事与工具性，不应成为另一个满强度主轴。

## 6. 功能阶段与突破

### 6.1 六阶段统一语义

| 阶段 | 东方名称 | 功能语义 | 功能经验 | 主技熟练度 | 主领域洞见 |
|---:|---|---|---:|---:|---:|
| 1 | 感应 | 接触并辨认力量来源 | 0 | 0 | 0 |
| 2 | 周天 | 稳定循环并重复入门方法 | 120 | 100 | 20 |
| 3 | 立基 | 建立可持续结构与主分支 | 360 | 250 | 20 |
| 4 | 凝相 | 形成个人表达与稳定形态 | 780 | 500 | 40 |
| 5 | 开域 | 短时影响局部现实规则 | 1500 | 700 | 60 |
| 6 | 渡劫/合道 | 承受体系终极代价并争取主权 | 2700 | 900 | 80 |

4500 功能经验、1000 主技熟练度和 100 领域洞见是阶段六后的圆满端点，不额外创造第七个通用阶段。

### 6.2 突破不是经验条自动领奖

突破至少需要以下条件：

- 经验门槛。
- 主技熟练门槛。
- 领域洞见门槛。
- 体系资格仍有效。
- 本地资源与设施已准备。
- 当前伤病、污染、债务和主体稳定在允许区间。
- 服务端为本次尝试冻结种子、代价和失败后果。

突破失败损失当前阶段未固化经验：

| 阶段 | 损失范围 |
|---:|---:|
| 1 | 10% 至 20% |
| 2 | 15% 至 25% |
| 3 | 25% 至 35% |
| 4 | 30% 至 40% |
| 5 | 40% 至 50% |
| 6 | 45% 至 50% |

保险只能提供损失下限，不能删除体系特有后果，也不能阻止真实死亡。

## 7. 技法熟练与四维质量

### 7.1 熟练度

| 熟练度 | 档位 | 能力表现 |
|---:|---|---|
| 0 至 99 | 生疏 | 只能在安全条件尝试 |
| 100 至 299 | 熟练 | 可重复执行基础版本 |
| 300 至 599 | 精研 | 可选择变体并降低浪费 |
| 600 至 849 | 通达 | 可在不利环境调整 |
| 850 至 1000 | 圆满 | 可稳定表达个人版本 |

熟练度不等于威力。每项技法还拥有四个 0 至 100 的质量轴：

| 质量轴 | 决定内容 |
|---|---|
| 掌握 | 是否理解完整结构与步骤 |
| 控制 | 是否能准确选择目标、强度和边界 |
| 稳定 | 是否能减少反噬、故障和资源波动 |
| 应变 | 是否能面对陌生环境、反制和临场变化 |

默认执行质量权重是掌握 35%、控制 30%、稳定 20%、应变 15%。具体技法可以覆盖这组权重，例如工程修复可提高稳定权重，决斗反击可提高应变权重。

### 7.2 练习收益

练习收益 = 基础值 × 难度适配 × 新颖度 × 正确性 × 导师质量 × 风险适配。

同一技法重复的新颖度依次为 1.0、0.75、0.55、0.40、0.30、0.25。单局主技熟练度最多 120，单个辅技最多 40，所有技法合计最多 180。

任何练习收益必须提供：

- 方法 ID。
- 行动与挑战标签。
- 正确性证据。
- 世界时间消耗。
- 资源消耗。
- 来源事件 ID。

## 8. 天赋系统

### 8.1 天赋定位

天赋回答“角色以什么方式打破常规”，技能回答“角色会做什么”。天赋不得替代技法资格。

| 天赋来源 | 特征 | 是否随身份死亡重置 |
|---|---|---|
| 种族/本相 | 先天承载与禁忌 | 通常是 |
| 出身 | 社会、教育和资源入口 | 是 |
| 体系 | 进入某力量源后的结构变化 | 是 |
| 传承 | 机构或师承带来的规则变体 | 是 |
| 觉醒 | 重大经历触发的机制变化 | 视事件而定 |
| 伤痕 | 带代价的永久行为变化 | 视轮回规则而定 |
| 谱系回响 | 上一世有限熟悉感 | 否，但占回响槽 |

### 8.2 容量与数值预算

| 参数 | 初始 | 上限 |
|---|---:|---:|
| 天赋容量 | 5 | 9 |
| 可选天赋槽 | 2 | 5 |
| 小天赋成本 | 1 | 1 |
| 大天赋成本 | 2 | 2 |
| 定义性天赋成本 | 3 | 3 |

同一效果通道的纯数值天赋总加成最多 10%，所有天赋倍率叠加后最多 1.20。定义性天赋必须互斥。理想天赋应改变条件、转换资源、重写风险或开放新策略，而不是简单提供伤害加成。

## 9. 技能树

### 9.1 每个传承的标准结构

| 节点类型 | 数量 | 目的 |
|---|---:|---|
| 技法解锁 | 10 | 提供动作与反应 |
| 技法变体 | 7 | 改变目标、代价、形态或时机 |
| 工具与经济 | 5 | 提供侦察、制作、恢复、交涉或资源策略 |
| 纯数值节点 | 2 | 填补必要平滑区 |
| 合计 | 24 | 一棵完整传承树 |

一个身份预计只拥有 35% 至 45% 的节点，不能填满整棵树。两项终极节点必须互斥。

### 9.2 点数与槽位

| 功能阶段 | 技能点预算 | 主动槽 | 反应槽 | 被动槽 | 领域槽 |
|---:|---:|---:|---:|---:|---:|
| 1 | 3 | 2 | 0 | 2 | 1 |
| 2 | 5 | 2 | 1 | 3 | 1 |
| 3 | 7 | 3 | 1 | 4 | 1 |
| 4 | 9 | 4 | 2 | 5 | 2 |
| 5 | 11 | 4 | 3 | 6 | 2 |
| 6 | 13 | 5 | 3 | 6 | 3 |

节点成本为一阶 1、二阶 1、三阶 2、终极 3。技能点只是分配预算，节点仍需熟练、阶段、领域、导师或来源证据。

### 9.3 洗点

| 洗点范围 | 成本 |
|---|---|
| 同节点微调 | 1 悟性点 + 已投入经验的 20% |
| 同分支重构 | 2 悟性点 + 已投入经验的 40% |
| 跨传承重构 | 3 悟性点 + 1 谱系印记 + 已投入经验的 50% |
| 更换主体系 | 当世禁止，只能通过轮回重构 |

洗点产生真实时间、导师、材料或契约成本。它不是菜单中的无损开关。

## 9A. 技能进阶材料

### 9A.1 技能点不是唯一门槛

一次技能进阶由五类条件组成：

| 条件 | 作用 |
|---|---|
| 技能点 | 决定树上如何分配 |
| 熟练度 | 证明角色真的会用前置技法 |
| 导师、手册或来源 | 证明知识从哪里获得 |
| 体系材料 | 承担实验、仪式、改造或稳定成本 |
| 世界证据 | 高阶能力必须在真实事件中完成资格证明 |

普通技能解锁默认不消耗稀有材料。只有技法变体、跨领域改造、终极节点和实际需要物质过程的技能才使用进阶材料。这样可以避免每个节点都变成“刷十个技能碎片”。

### 9A.2 技法层级需求

| 目标技法阶 | 技能点 | 最低熟练 | 训练时间 | 材料需求 |
|---:|---:|---:|---:|---|
| 1 | 1 | 0 | 2 小时 | 无 |
| 2 | 1 | 100 | 6 小时 | 2 份本体系主材 |
| 3 | 2 | 250 | 12 小时 | 3 主材 + 1 稳定材 |
| 4 | 2 | 500 | 24 小时 | 2 稳定材 + 1 催化材 |
| 5 | 3 | 700 | 48 小时 | 2 催化材 + 1 领域材 |
| 6 | 3 | 900 | 96 小时 | 3 领域材 + 1 极点材 + 世界领域证明 |

二至五阶材料价值上限分别控制在预期三局收入的 5%、15%、35% 和 75%。六阶是世界事件目标，不使用普通商店价格保底。

### 9A.3 不同节点的材料政策

| 节点 | 默认材料 |
|---|---|
| 技法解锁 | 无稀有材料，要求知识来源与练习 |
| 技法变体 | 一套体系试剂或改造材料 |
| 工具/经济节点 | 工具、工位、执照或机构资格 |
| 纯数值节点 | 无稀有材料，只要求练习阈值 |
| 终极节点 | 领域或极点催化物 + 世界事件证据 |

coin 可以购买材料、导师时间和设施服务，但不能直接购买熟练度、技能点或世界证据。

## 9C. 修行材料如何获取

### 9C.1 六条主要路径

| 路径 | 典型内容 | 主要约束 |
|---|---|---|
| 世界生产 | 灵田、矿场、织坊、炼厂、工厂、实验室 | 时间、劳动、设施、原料 |
| 采集与开采 | 药草、矿脉、领域生态、合法生物样本 | 储量、再生、所有权、采集技能 |
| 合同与组织分配 | 宗门、学院、神殿、企业、研究机构 | 预算、声望、义务、任务结果 |
| 市场购买 | 商店、拍卖、委托、黑市 | coin、库存、法律、运输 |
| 拆解与回收 | 装备、残骸、失效装置、合法战利品 | 所有权、品相、拆解技能 |
| 特定世界事件 | 领域异常、天劫、遗迹、原型试验 | 事件资格、真实风险、唯一证明 |

零至三阶非唯一材料至少有三条获取路径，四阶材料至少两条。极点材料可以只有一个主事件，但删除该事件时必须提供 successor。

### 9C.2 采集公式

产量 = floor(基础产量 × 地点丰度 × 工具质量 × 采集效率 × 环境状态 × 可持续管理 × 种子方差)

种子方差限制在 0.90 至 1.10。资源点必须记录储量、再生率、所有权、开采权、位置和枯竭事件。反复采集会真实消耗储量，不通过隐藏掉率惩罚玩家。

敌人只能掉落其携带库存、合法装备、可解释的生物组织或场景回收物。机械敌人不会掉灵草，普通野兽不会掉技能书，Boss 也不能凭空掉无关体系催化物。

## 10. 战斗力标准：十维准备向量

### 10.1 为什么没有总战斗力

一个擅长灵魂防护但机动不足的角色，面对夺舍者可能占优，面对高速物理猎手可能吃亏。把两种结果压成一个总战斗力，会同时破坏多体系设定、装备价值、情报价值和 Roguelite 构筑。

因此面板展示十维向量：

| 维度 | 说明 |
|---|---|
| 攻势 | 制造有效压力和完成终结 |
| 防护 | 抵挡、减伤、屏障和规避致命后果 |
| 机动 | 改变距离、位置和行动窗口 |
| 控制 | 限制敌方行动、资源和空间 |
| 感知 | 发现目标、弱点、欺骗和环境变化 |
| 续航 | 长时间维持行动与恢复 |
| 储备 | 可调动的能量、弹药、法器和备用方案 |
| 污染抗性 | 抵御异化、心智侵入和体系反噬 |
| 协同 | 与队友、召唤、装置和环境组合 |
| 适应 | 面对未知机制和反制时调整 |

### 10.2 向量来源

| 来源 | 默认权重 |
|---|---:|
| 六项属性投影 | 35% |
| 已装备技法 | 30% |
| 装备与消耗品 | 20% |
| 准备与情报 | 15% |

每个技法可以覆盖默认属性投影。例如工程炮台可以把攻势更多投影到智力、材料和准备，而不是强行依赖力量。

### 10.3 状态与环境

| 因素 | 允许范围 |
|---|---:|
| 当前状态倍率 | 0.60 至 1.15 |
| 环境倍率 | 0.70 至 1.30 |
| 克制倍率 | 0.75 至 1.25 |
| 合并后的最终倍率 | 0.55 至 1.45 |

限制最终倍率可以避免属性、装备、稀有度、阵营、祝福、赛季和难度连续相乘导致指数爆炸。

### 10.4 具体遭遇适配度

遭遇先定义十维权重，权重之和必须为 1。适配度只对当前遭遇有效：

适配度 = 各维度的“遭遇权重 × 有效准备值 × 克制因子”之和。

威胁点换算为压力：

遭遇压力 = 100 × TP / (TP + 120)

首版胜率估计：

胜率 = 1 / (1 + exp(-(适配度 - 遭遇压力) / 12))

胜率只用于仿真、匹配提示和内容 QA。正式裁定还必须读取目标、行动顺序、资源消耗、环境、敌方策略和确定性种子。

### 10.5 UI 只显示区间

| 估计胜率 | 提示 |
|---:|---|
| 低于 25% | 危急 |
| 25% 至 45% | 劣势 |
| 45% 至 55% | 胶着 |
| 55% 至 75% | 有利 |
| 高于 75% | 压制 |

UI 不展示一个永久数字，也不能用该区间计算任务评分或直接提高奖励。

## 11. 单局 Roguelite 结构

### 11.1 标准局

| 项 | 值 |
|---|---:|
| 最短主线 | 8 节点 |
| 标准主线 | 10 节点 |
| 最长主线 | 12 节点 |
| 终局 | 固定 Boss |
| 侧枝威胁 | 主线同深度的 65% |
| 侧枝奖励 | 主线同深度的 70% |

标准 10 节点承担平衡基线。8 节点版压缩恢复窗，12 节点版增加可选侧枝，但不改变终局主线压力。

### 11.2 威胁曲线

普通节点 TP = round(45 × 1.18 的 depth-1 次方)。

精英节点 = 普通节点 × 1.55。Boss 节点 = 普通节点 × 2.80。

| 深度 | 普通 TP | 精英 TP | Boss TP | 目标构筑容量 |
|---:|---:|---:|---:|---:|
| 1 | 45 | 70 | 不适用 | 16 |
| 2 | 53 | 82 | 不适用 | 18 |
| 3 | 63 | 98 | 不适用 | 20 |
| 4 | 74 | 115 | 不适用 | 22 |
| 5 | 87 | 135 | 不适用 | 24 |
| 6 | 103 | 160 | 不适用 | 24 |
| 7 | 121 | 188 | 不适用 | 26 |
| 8 | 143 | 222 | 不适用 | 26 |
| 9 | 168 | 260 | 不适用 | 28 |
| 10 | 198 | 307 | 554 | 30 |

TP 必须拆到攻势、控制、装甲、召唤和环境五个预算通道，禁止只增加生命值。

### 11.3 敌人预算

| 敌人类型 | TP |
|---|---:|
| 低级杂兵 | 12 至 18 |
| 高威胁杂兵 | 20 至 28 |
| 支援或控场 | 22 至 30 |
| 精英 | 48 至 60 |
| 小 Boss | 110 至 140 |
| Boss 阶段体 | 180 至 220 |

敌人组合还必须满足角色职责、环境合理性、来源库存和世界位置，不允许因为预算刚好就把不应出现的单位传送进场。

### 11.4 节点概率

| 深度 | 普通战斗 | 精英 | 商店 | 恢复 | 事件/缓存 |
|---|---:|---:|---:|---:|---:|
| 1 至 3 | 70% | 8% | 6% | 8% | 8% |
| 4 至 6 | 60% | 12% | 8% | 8% | 12% |
| 7 至 8 | 52% | 16% | 10% | 8% | 14% |
| 9 | 44% | 20% | 10% | 10% | 16% |
| 10 | Boss | 0 | 0 | 0 | 0 |

路线生成先过滤资格与世界条件，再做权重，不允许先抽取后隐藏。

### 11.5 受控三选一

| 槽位 | 目标概率 |
|---|---:|
| 当前构筑主标签 | 55% |
| 相邻协同标签 | 30% |
| 生存、经济或纠错 | 15% |

每次选择至少有一项支持当前构筑或解决当前资源危机。锁定内容、未选路线、未满足资格的内容在加权前就必须移出候选池。

### 11.6 稀有度

| 深度 | 普通 | 稀有 | 史诗 | 传奇 |
|---|---:|---:|---:|---:|
| 1 至 3 | 60% | 28% | 10% | 2% |
| 4 至 6 | 52% | 30% | 14% | 4% |
| 7 至 8 | 42% | 30% | 20% | 8% |
| 9 至 10 | 34% | 28% | 26% | 12% |

稀有度描述构筑复杂度、条件性和内容稀缺，不直接乘以最终伤害。传奇效果必须带有条件、代价、互斥或明显构筑方向。

### 11.7 局内构筑容量

BP 不是货币，而是同时激活多少复杂效果的容量：

构筑容量 = min(32, 16 + 2 × 普通节点完成数 + 3 × 精英完成数 + 5 × Boss 阶段完成数)

| 模组类型 | BP 成本 |
|---|---:|
| 普通模组 | 2 至 3 |
| 协同模组 | 4 至 5 |
| 稀有模组 | 6 至 8 |
| Boss 模组 | 9 至 12 |

每局最多一个主核心、两个支撑核心和三个工具位。BP 归零，构筑内容不带出。

## 12. 难度与对局强度

### 12.1 难度档

| 档位 | 威胁倍率 | 可申领奖励倍率 |
|---|---:|---:|
| 剧情 | 0.80 | 0.75 |
| 标准 | 1.00 | 1.00 |
| 老练 | 1.15 | 1.12 |
| 梦魇 | 1.32 | 1.25 |
| 深渊 | 1.52 | 1.40 |

奖励增长低于威胁增长，防止最高难度成为唯一效率路线。

### 12.2 任务风险级别

| 风险 | 威胁倍率 | 合同申领倍率 |
|---|---:|---:|
| 低 | 0.85 | 0.80 |
| 中 | 1.00 | 1.00 |
| 高 | 1.15 | 1.15 |
| 极端 | 1.35 | 1.40 |

难度档是玩家选择的规则配置，风险级别是世界中任务本身的客观条件。两者必须分别记录，不能混成一个“高强度”标签。

### 12.3 强度不是属性奖励

高强度只会带来：

- 更高 TP 与更复杂敌人组合。
- 更高伤病、污染、资源损耗与撤离风险。
- 更高的合同申领上限，但仍受托管或库存限制。
- 更高的熟练度挑战适配系数。

高强度不会直接指定增加体魄、意志或任何属性。

## 13. 奖励、商店与经济守恒

### 13.1 奖励来源

| 奖励 | 合法来源 |
|---|---|
| coin | 合同托管、组织预算、敌方携带账户、销售、继承、审计铸造 |
| aether | 储备库、场景储层、物品转化、合法回收 |
| 商品 | 场景库存、运输、生产、敌方库存、回收 |
| 传奇度 | 见证、档案、机构认可 |
| 技法经验 | 行动证据、导师评价、服务端裁定 |
| 谱系印记 | 身份真实终结后的轮回结算 |

没有来源账户或库存时，任务可以提供名誉、关系、权限、债权或未来合同，但不能凭空发放物质奖励。

### 13.2 首版奖励上限

| 节点 | 深度 1 至 3 | 深度 4 至 6 | 深度 7 至 8 | 深度 9 至 10 |
|---|---|---|---|---|
| 普通 coin | 8 至 12 | 12 至 18 | 18 至 26 | 26 至 36 |
| 普通 aether | 0 至 1 | 1 至 2 | 1 至 3 | 2 至 4 |
| 精英 coin | 20 至 30 | 30 至 44 | 44 至 60 | 60 至 82 |
| 精英 aether | 1 至 2 | 2 至 3 | 3 至 5 | 5 至 8 |

Boss 上限为 coin 120 至 180、aether 8 至 12、三个特化核心中选择一个。以上数值是可申领上限，必须由托管、库存或回收来源支持。

### 13.3 商店

| 项目 | 价格 | 效果 |
|---|---|---|
| 小治疗 | 12 + 2 × 深度 | 回复 25% 生命 |
| 中治疗 | 20 + 3 × 深度 | 回复 45% 生命 |
| 净化 | 16 + 2 × 深度 | 清除一个允许清除的负面状态 |
| 重掷 | 6 + 深度 | 重生成一次合法候选包 |
| 构筑件 | 18 + 3 × 深度 | 购买普通构筑项 |
| 稀有构筑件 | 35 + 5 × 深度 | 购买稀有构筑项 |

商店交易必须把 coin 转入真实商户或组织账户。恢复节点也要消耗时间、食物、药品或场景供给。

### 13.4 哪些资源可以在商店消费

| 资源 | 商店角色 | 是否直接消费 |
|---|---|---|
| coin | 默认结算货币 | 是 |
| aether | 可交易商品、能源和施法材料 | 只有商品明确接受时 |
| legend | 名望、资格和担保能力 | 否 |
| stamina | 身份当前状态 | 否 |
| focus | 身份当前状态 | 否 |
| 技能点 | 技能树分配预算 | 否 |
| 悟性点 | 洗点与理解预算 | 否 |
| 谱系印记 | 跨世继承资格 | 不能在世界商店使用 |

coin 是唯一默认标价货币。aether 可以被买卖，也可以被部分专业机构直接接受，但它首先是守恒的商品与能源，不是第二套万能金币。

legend 不允许“花掉购买装备”。它只用于满足接触资格、获得报价、进入拍卖、担保合同或暂时质押信用。担保失败可以导致 legend 下降，但普通交易不会扣除 legend。

### 13.5 玩家支出不等于世界货币销毁

购买一瓶药时，coin 从玩家账户转入药店账户。这是玩家支出，也是世界流通，但不是世界级货币回收。

| 流程 | 玩家余额 | 世界总 coin |
|---|---:|---:|
| 向商店购买 | 下降 | 不变 |
| 支付训练费 | 下降 | 不变，转入导师或机构 |
| 支付税费 | 下降 | 不变，转入政府账户 |
| 保险保费 | 下降 | 不变，进入保险准备金 |
| 合同托管 | 暂时锁定 | 不变 |
| 审计退役货币 | 下降或不变 | 下降 |
| 货币永久离开模拟世界 | 下降或不变 | 下降 |

因此通胀不能用“玩家在商店花了多少钱”衡量。世界层必须分别监控铸造、退役、货币总量、商品总量、价格指数和流通速度。

### 13.6 商店类型

| 商店 | 主要供应 | 补货方式 | 是否可在局内出现 |

| 战地军需 | 消耗品、构筑件、基础维修、情报改线 | 合同预留、商人携带、可达补给缓存 | 是 |

| 黑市 | 违禁品、未授权服务和情报 | 走私、盗窃、地下生产 | 条件节点 |

打开和关闭 UI 不会补货。库存只能由 WorldTick、生产、运输、NPC 出售、合同预留或世界事件改变。

### 13.7 价格公式

最终价格：

价格 = max(1, floor(基础价 × 稀缺 × 需求 × 紧急 × 品相 × 合法性 × 关系) + 服务费)

| 乘区 | 范围 |
|---|---:|
| 地区稀缺 | 0.75 至 1.80 |
| 当前需求 | 0.85 至 1.35 |
| 局内紧急 | 1.00 至 1.25 |
| 物品品相 | 0.60 至 1.20 |
| 合法性风险 | 1.00 至 2.00 |
| 商户关系 | 0.85 至 1.15 |
| 所有乘区合并 | 最低 0.65，最高 2.50 |

报价由服务端冻结，有效期为 15 个世界分钟。UI 必须显示基础价、稀缺、关系、税费和风险等拆分信息，不能只给一个无法解释的红色数字。

### 13.12 原子交易

每笔购买按以下顺序结算：

1. 服务端生成报价。
2. 预留商户库存或服务时间。
3. 预留买方 coin 或被接受的 aether。
4. 原子转移货币。
5. 原子转移物品、所有权或服务结果。
6. 写入包含交易双方和前后余额的收据。

任一步失败时整笔回滚。禁止出现扣钱未得物、得物未扣钱、负余额、幽灵库存、重复请求双倍购买和部分结算。

| 负余额 | 0 |
| 幽灵库存 | 0 |
| 商户超余额收购 | 0 |

## 13B. 生产职业：铸造与缝纫

### 13B.1 共同生产流程

1. 校验配方、执照和知识来源。
2. 计算材料、工时、工位、燃料与服务报价。
3. 原子预留材料、工位和劳动时间。
4. 使用冻结 seed 执行生产。
5. 生成成品、废料和副产物。
6. 转移成品所有权。
7. 写入完整生产收据。

NPC 与玩家使用同一套配方和库存守恒。玩家不会铸造或缝纫时，可以委托真实 NPC，但 NPC 需要材料、工位、时间和工资。

### 13B.2 工艺评分

工艺评分由职业熟练 35%、配方掌握 20%、工具 15%、工位 15%、材料适配 10% 和工匠状态 5% 组成，再扣除复杂度与污染。

| 得分 | 品质 | 数值预算 | 改造槽 | 拆解回收 |
|---:|---|---:|---:|---:|
| 0 至 34 | 失败品 | 60% | 0 | 30% |
| 35 至 54 | 可用 | 85% | 0 | 40% |
| 55 至 69 | 精良 | 100% | 1 | 50% |
| 70 至 84 | 优质 | 105% | 2 | 60% |
| 85 至 94 | 大师作 | 110% | 2 + 标志特性 | 70% |
| 95 至 100 | 独一品 | 110% | 3 + 条件特性 | 70% |

品质不会把所有属性连续相乘。原始装备预算倍率硬上限为 1.10，高品质主要增加耐久、可维护性、改造槽、稳定性和条件特性。

### 13B.3 铸造系统

铸造分为选材、熔炼、成形、热处理、装配和表面/术式处理。主要消耗金属、助熔剂、燃料、结构件、导体和体系催化物。

| 配方 | 主要材料 | 工时 | 最低熟练 | 主要效果 |
|---|---|---:|---:|---|
| 野战短刃 | 铁合金 3、助熔剂 1、硬木 1、炉焦 1 | 4 | 100 | 攻势 6、控制 2 |
| 强化战刃 | 铁合金 4、助熔剂 2、精密零件 1 等 | 8 | 250 | 攻势 10、控制 3 |
| 共鸣导刃 | 共鸣合金 4、聚焦晶 1、强化缝线 1 等 | 18 | 500 | 攻势 12、储备 7，但污染抗性 -4 |
| 领域锚甲板 | 领域锚合金 6、域玉 1、共鸣丝线 2 等 | 40 | 800 | 防护 16、污染抗性 15、机动 -8 |
| 金工维修包 | 铁合金、助熔剂、精密零件各 1 | 2 | 100 | 局内恢复 20 耐久 |

共鸣和领域装备仍要求使用者拥有对应体系资格。工匠能造出导体，不等于购买者因此学会使用超凡力量。

### 13B.4 缝纫系统

缝纫分为制版、裁剪、拼接、缝合、内衬、加固、染整和体系调谐。主要消耗布、皮革、线、扣件、纤维和术式材料。

| 配方 | 主要材料 | 工时 | 最低熟练 | 主要效果 |
|---|---|---:|---:|---|
| 旅行外套 | 机织布 4、皮革 2、标准缝线 2、扣件 1 | 6 | 100 | 防护 4、续航 2 |
| 强化行装 | 机织布 4、皮革 3、强化缝线 2 等 | 10 | 250 | 防护 9、续航 4、机动 -2 |
| 远征挂载具 | 皮革 3、机织布 2、强化缝线 2 等 | 10 | 300 | 储备 5、协同 3、快捷格 +1 |
| 以太织袍 | 以太纤维 4、共鸣丝线 2、术印墨 1 等 | 20 | 500 | 控制 7、储备 10、防护 3 |
| 领域披风 | 领域丝 4、共鸣丝线 3、身份锚 1 等 | 40 | 800 | 污染抗性 15、控制 8、机动 -4 |
| 织物维修包 | 机织布 2、标准缝线 2、皮革 1 | 2 | 100 | 局内恢复 20 耐久 |

缝纫可以制作背包、挂载具和快捷袋，但不能绕过局外成长上限。所有缝纫容器合计最多增加两个局内战利品空间或一个快捷使用格，并继续占用部署容量。

### 13B.5 耐久、维修与拆解

耐久范围为 0 至 100。维修材料：

维修材料 = ceil(基础材料数量 × 缺失耐久比例 × 0.60)

普通维修可能损失 1 至 3 点最大耐久，大师维修可以避免。拆解返还 40% 至 70% 的普通材料，取决于物品状态、工匠熟练和工位。极点材料不保证返还，防止复制高阶催化物。

### 13B.6 委托价格

委托价格 = 材料参考价 + 工时 × 工匠时薪 × 复杂度倍率 + 工位费 + 风险费 + 税。

六阶工匠基础时薪依次为 3、5、8、12、18、25 coin。复杂度倍率为 1.0 至 2.5。委托金转入真实工匠或组织账户。

### 13B.7 配方获取

配方可以来自导师教学、合法购买、机构许可、研究、逆向工程和世界事件。RAG 可以帮助召回已经掌握的配方，但不能因为检索到相关文本就直接解锁。

配方必须记录 recipeId、recipeVersion、来源事件、许可证、适用工位和失效条件。

## 14. 撤离、失败与死亡

### 14.1 结算矩阵

| 结果 | 已确认申领保留 | 未确认申领保留 | 练习证据保留 | 局内构筑 |
|---|---:|---:|---:|---:|
| 完整完成 | 100% | 70% | 100% | 0% |
| 主动撤离 | 100% | 50% | 80% | 0% |
| 强制撤离 | 75% | 25% | 60% | 0% |
| 任务失败但存活 | 80% | 30% | 50% | 0% |
| 服务端确认死亡 | 20% | 10% | 35% | 0% |

“已确认”表示物品已经被锁定、见证、托管或完成合法转移。“未确认”表示仍位于危险场景、缺少运输、所有权未明确或尚未通过结算。

### 14.2 任务失败不等于死亡

真实死亡必须由世界服务端依据身体状态、地点、时间、见证、医疗和其他既有条件确认。LLM 文本、Boss 演出或单局失败不能直接宣布身份死亡。

## 15. 局外成长：物品带入、部署容量与谱系

### 15.1 物品格与部署容量分离

物品格回答“能带几类东西”，部署容量回答“能带多重、多复杂的东西”。只增加格数会形成最优稀有物品堆叠，只有容量会降低可读性，因此两者同时存在。

| 参数 | 初始 | 30 局上限 |
|---|---:|---:|
| 物品带入格 | 3 | 5 |
| 部署容量 | 6 | 10 |
| 快捷使用格 | 2 | 3 |
| 同类物品上限 | 2 | 2 |
| 主核心上限 | 1 | 1 |

| 稀有度 | 部署成本 |
|---|---:|
| 普通 | 1 |
| 优良 | 2 |
| 稀有 | 3 |
| 史诗 | 4 |
| 神话 | 5 |

任务物品不能作为普通带入物。任何被保险、借用、租赁或绑定的装备都必须在事件中记录所有权和返还条件。

### 15.2 回响格不是物品格

回响格用于下一身份开局携带有限熟悉感或遗产锚点：

| 内容 | 是否允许 |
|---|---|
| 小天赋回响 | 允许 |
| 技法熟悉度回响 | 允许 |
| 分支锚点 | 允许 |
| 保险凭证 | 允许 |
| 低阶物品或契约残响 | 允许 |
| 完整上一世身份 | 禁止 |
| 完整境阶 | 禁止 |
| 全部技能树 | 禁止 |
| 无继承事件的世界所有权 | 禁止 |

回响格从 1 增长到 6。它扩大开局方向，不保证开局强度。

### 15.3 保险

| 保险 | 效果 | 不能做什么 |
|---|---|---|
| 物品返还险 | 满足条件时返还一件带入物 | 不能复制物品 |
| 技法回响险 | 保留一项有限熟悉度 | 不能保留完整技能 |
| 突破损失险 | 设置经验损失下限 | 不能消除体系代价 |

保险层数从 0 增长到 2。保险费必须真实转入机构或组织账户，理赔也必须来自准备金或债权事件。

## 16. 0 至 30 局成长节奏

### 16.1 标准队列

| 局数 | 目标阶段 | 回响格 | 物品格 | 部署容量 | 保险层 | 技能树占有率目标 |
|---|---|---:|---:|---:|---:|---:|
| 0 至 2 | 阶段 1 | 1 | 3 | 6 | 0 | 12% |
| 3 至 6 | 阶段 1 至 2 | 2 | 3 | 6 | 0 | 20% |
| 7 至 11 | 阶段 2 至 3 | 3 | 4 | 7 | 1 | 28% |
| 12 至 17 | 阶段 3 | 4 | 4 | 8 | 1 | 35% |
| 18 至 24 | 阶段 3 至 4 | 5 | 5 | 9 | 2 | 40% |
| 25 至 30 | 阶段 4 至 5 | 6 | 5 | 10 | 2 | 45% |

阶段六是高表现队列的冲刺，不是 30 局保底。新手、普通、熟练和极端玩家应在相同局数下呈现不同的知识、风险和资源轨迹，而不是只差一条等级经验。

### 16.2 单局功能经验软上限

设 L 为已完成局数，R 为单局原始功能经验：

软上限 C(L) = 60 + 6L + 2 × max(0, L - 10) + 2 × max(0, L - 20)。

| 原始经验区间 | 有效经验 |
|---|---|
| R 小于等于 C | R |
| C 小于 R 小于等于 1.8C | C + 0.5 × (R - C) |
| R 大于 1.8C | C + 0.4C + 0.2 × (R - 1.8C) |

该公式只抑制单局刷爆，不替代体系资格、本地资源、世界时间和突破条件。

任务分数与难度的相关系数绝对值必须低于 0.15。同一合同在目标不变时，仅改变敌人预算带来的平均评分偏移不得超过正负 5 分。

## 19. RAG 面板与记忆变化

### 19.1 RAG 记录什么

RAG 只保存对未来理解和选择有价值的摘要：

| 层级 | 上限 |
|---|---:|
| 节点 capsule | 128 tokens |
| 路线 capsule | 96 tokens |
| 单局 capsule | 160 tokens |
| 每局持久显著记忆 | 最多 3 条 |

每条摘要必须携带 sourceEventIds，具体余额、库存、伤病和解锁只保存指针，不复制成另一份事实。

### 19.2 显著度

显著度 = 30% 后果 + 20% 新颖度 + 20% 身份相关 + 20% 世界影响 + 10% 见证与证据。

显著度达到 70 才可固化。重复三次可触发合并，但不能因重复而伪造更高事实权威。

### 19.3 RAG 面板

| 面板值 | 范围 | 正常变化 |
|---|---:|---|
| 显著记忆数 | 0 至 3 | 只在重要事件后增加 |
| Canon 覆盖 | 0 至 1 | 来源事件和固化事实越完整越高 |
| 检索置信 | 0 至 1 | 语义、词法与权威指针一致时上升 |
| 新颖度 | 0 至 100 | 重复路线持续下降 |
| 记忆负载 | 0 至 100 | 合并摘要后可下降 |
| 可追溯度 | 0 至 1 | sourceEventIds 完整时接近 1 |

不应出现“每做一步所有 RAG 数值都增长”的现象。正常十局观察中，多数普通节点只改变临时 capsule，只有少数关键事件改变持久面板。

## 20. 服务端流程

### 20.1 开局

1. 读取角色、世界、谱系和库存的 canonical 投影版本。
2. 校验主体系、传承、装备所有权、物品格与部署容量。
3. 冻结合同目标、隐藏目标、托管预算、风险级别和合法候选池。
4. 生成 seed、seedHash、catalogHash 和版本收据。
5. 建立 run 账本，局内数据不得提前写回身份成长。

### 20.2 节点结算

1. 根据路线资格与世界位置生成候选。
2. 使用 TP 构造合法遭遇。
3. 读取角色十维向量和当前状态。
4. 服务端裁定行动、资源变化、伤病、污染、目标与证据。
5. 生成临时练习证据和待确认申领。
6. 生成节点 capsule，但不立即固化为世界记忆。

### 20.3 单局结算

1. 确认完整完成、撤离、失败或真实死亡。
2. 按结算矩阵转换申领与练习证据。
3. 从托管或库存释放物质奖励。
4. 计算任务评分，评分不得读取战斗准备度。
5. 应用反刷热度和世界需求变化。
6. 选择最多三条显著记忆并写入 solidification 请求。
7. 清空局内构筑。
8. 写入可重放结算收据。

## 22. 迁移方案

### 22.1 现有字段

| 现有内容 | 迁移决策 |
|---|---|
| strength/agility/physique/intellect/willpower/spirituality | 保留为 canonical 六属性 |
| coin/aether/stamina/focus/legend | 保留，不新建重复货币 |
| food/water/medicine/materials/fuel/aether | 保留为世界商品 |
| Journey 目标、路线、评分和确定性方差 | 复用并扩展版本收据 |
| 现有 exploration combatPower | 标记弃用，迁移为遭遇专用 suitability 投影 |
| 每局按强度自动 +1 属性 | 删除，改为证据经验事件 |
| 绑定物品 | 保留所有权，新增带入与保险事件 |
| World Memory solidified canon | 保留，新增单局 capsule 与显著度 |

### 22.2 兼容规则

- 旧事件 ID 永不重写。
- 旧属性值原样保留，不追溯扣减。
- 旧 combatPower 只用于读取旧收据，不再参与新裁定。
- 删除或更名地区、势力、资源、传承和任务类型必须提供 successor。
- 旧 seed 在旧 balanceVersion 下仍可重放。
- 新 balanceVersion 不得改变已完成任务的历史评分。
- 投影失败时可以重建，不能回写修正 canonical ledger。

## 25. AAA 级红线

以下任一情况出现，版本不得进入实现或发布：

- 新增第二套事实数据库。
- RAG 或 LLM 文本直接写余额、奖励、控制权、死亡或解锁。
- 新增货币但没有来源、回收、转移和通胀面板。
- 任务奖励没有托管、预算、库存或合法生成源。
- 路线选择只改变文案，不改变至少一个可验证世界谓词。
- 锁定、未选或未解锁内容进入候选池、推荐或 RAG。
- 重新引入全局战斗力、等级碾压或稀有度乘区。
- 局外成长让零准备身份稳定碾压高风险内容。
- 属性仍按对局强度自动增长。
- 公式没有软上限、倍率预算、失败成本或经济回收。
- 普通敌人掉落与其库存、生理结构或所在场景无关的技能材料。
- 技能点、熟练度、境界或世界证明可以在普通商店直接购买。
- NPC 制造不消耗材料、工时、工位和工资。
- RAG 检索文本可以直接解锁配方。
- 铸造或缝纫容器绕过物品格与部署容量上限。
- 删除内容没有 successor 和重放证明。
- 没有单地区垂直切片就直接扩展七套体系。

## 26. 已知风险与后续校准

| 风险 | 当前控制 | 后续证据 |
|---|---|---|
| TP 曲线过陡 | 10 节点标准局、恢复窗和撤离率门槛 | 10,000 局蒙特卡洛 |

| 七体系被功能阶段同质化 | 本地资源、资格、代价和风险独立 | 三体系垂直切片对比 |
| 经济奖励不足导致体验差 | 可用关系、权限、债权和未来合同补足 | 玩家价值感测试 |

## 27. 完成定义

本 Spec 只有在以下条件全部满足后才可标记为 Implemented：

- balance catalog 被运行时读取并带版本 hash。
- 强度自动加属性逻辑被移除。
- 新属性增长有事件证据和世界时间成本。
- 十维准备向量取代新流程中的全局 combatPower。
- 三体系垂直切片拥有独立资源与代价。
- 天赋、技能树、局内构筑和谱系回响分别结算。
- 技能与境阶进阶材料拥有来源、替代获取路径、预留和消费事件。
- 铸造、缝纫、维修、拆解与委托遵守同一材料守恒和世界时间。
- 带入格、部署容量和保险拥有真实所有权与经济事件。
- 奖励托管与库存守恒通过。
- 商店库存、报价、购买、回收、服务和保险全部使用原子交易。
- coin 支出与世界货币退役分账统计，aether 不被当成第二套万能货币。
- 任务评分与战斗准备解耦通过统计门槛。
- RAG 面板只由可追溯记忆变化驱动。
- 同版本同 seed 重放差异为零。
- 旧事件、旧 ID 和 successor 迁移全部通过。

在这些实现完成前，本文与数据目录只代表可执行的 v1 数值基线，不代表已经上线的游戏规则。
