# 黑曜纪元 Agent 探索者共享大世界 100 轮矩阵式对抗验证

验证对象：`docs/superpowers/specs/2026-06-23-agent-explorer-shared-world-spec.md`

## 100 轮串行验证

### Round 001

Matrix: UX
视角：第一次打开页面的新手。
攻击问题：用户 30 秒内看见“agent、战报、审档、设定主张、声望”会不会直接懵掉。
当前观察：spec 有概念完整性，但首局入口仍偏重系统说明。
判定：需要修订 M001。首局必须只呈现一个 agent、一个推荐委托、一个明确按钮和一个“不会上传 API Key”的安全提示。

### Round 002

Matrix: UX
视角：不懂世界观但想试一下的轻度用户。
攻击问题：用户没有读过黑曜纪元资料，能否理解为什么要派 agent。
当前观察：spec 依赖世界锚点，但未要求首局锚点自动推荐。
判定：需要修订 M001。首局使用“推荐入场合同”，默认腐林/湿谷/城市管道之一，不要求用户先理解完整图谱。

### Round 003

Matrix: UX
视角：谨慎用户。
攻击问题：用户会不会不信 agent，觉得它在黑箱乱写。
当前观察：spec 有战报和高危授权，但缺少 agent 决策解释。
判定：需要修订 M002。每个关键行动要显示“依据、风险、替代方案、消耗”，形成 agent 信任条。

### Round 004

Matrix: UX
视角：想亲自参与的用户。
攻击问题：agent 自动跑导致用户变成旁观者。
当前观察：spec 第 29.21 提到手动接管，但不是首版核心。
判定：需要修订 M003。MVP 也应至少允许“暂停 agent、插入一条指令、手动接管一次关键事件”。

### Round 005

Matrix: UX
视角：害怕不可逆选择的用户。
攻击问题：用户授权高危行为后后悔，是否马上流失。
当前观察：spec 有高危授权，无悔棋/确认分级。
判定：需要修订 M003。高危授权分二级确认；未进入服务器结算前允许撤回客户端下一步。

### Round 006

Matrix: UX
视角：失败后回来的用户。
攻击问题：agent 死亡、失踪或污染会不会让用户觉得账号废了。
当前观察：spec 第 29.22 有纪念和继承，但需要更强回流。
判定：需要修订 M004。死亡/失踪必须产生“继任线索、遗物、找回委托、纪念页”，并在下一局开场出现。

### Round 007

Matrix: UX
视角：追求爽感的用户。
攻击问题：结算如果只有分数和文字，会不会没有“掉落”快感。
当前观察：spec 有设定卡析出和地图点亮，但缺少结算节奏要求。
判定：需要修订 M001/M006。结算必须分阶段展示：战报封存、评分、设定析出、声望变化、地图影响、下一步委托。

### Round 008

Matrix: UX
视角：移动端用户。
攻击问题：事件卡、地图、结算、设定卡都很复杂，移动端是否无法玩。
当前观察：spec 未明确移动端优先的信息层级。
判定：需要修订 M001。MVP 移动端首屏只能有当前委托、agent 状态、高危请求和下一步，不展示完整图谱。

### Round 009

Matrix: UX
视角：听觉/视觉敏感用户。
攻击问题：低语、闪烁、污染特效可能造成不适。
当前观察：spec 有声音设计，无低刺激模式。
判定：需要修订 M005。所有声景、闪烁、抖动、低语默认可关闭，并提供低刺激模式。

### Round 010

Matrix: UX
视角：不愿意花模型费用的用户。
攻击问题：用户担心一次探索烧太多 API 费用。
当前观察：spec 有调用预算，但体验上需要预算预估。
判定：需要修订 M001/M005。入场合同必须展示预计模型调用和“低成本模式/摘要模式”。

### Round 011

Matrix: UX
视角：忙碌用户。
攻击问题：异步派遣后，用户回来不知道发生了什么。
当前观察：spec 有战报，但没有回访摘要要求。
判定：需要修订 M006。每次回访先显示三行摘要：agent 状态、带回成果、需要用户处理的决策。

### Round 012

Matrix: UX
视角：成就驱动用户。
攻击问题：用户不知道长期目标是什么，只看到一局一局跑。
当前观察：spec 有声望和阵营特长，但缺少清晰路线图展示。
判定：需要修订 M006。agent 档案页展示当前最近三个可达目标和一个高位长期目标。

### Round 013

Matrix: UX
视角：叙事沉浸用户。
攻击问题：结构化审档太理性，削弱黑曜纪元气质。
当前观察：spec 有档案官语言，但许多治理术语偏后台。
判定：需要修订 M001。前台用世界内文案，后台术语隐藏在“详情”里。

### Round 014

Matrix: UX
视角：想比较 agent 的用户。
攻击问题：不同 agent 的差异是否足够可感。
当前观察：spec 有 temperament/riskPolicy，但没有差异反馈。
判定：需要修订 M002/M028。结算中要显示“本 agent 因何种性格做出何种选择”，让培养有反馈。

### Round 015

Matrix: UX
视角：害怕输错 API Key 的用户。
攻击问题：Key 输入体验是否会吓退用户。
当前观察：spec 有不上传 Key，但没有本地测试/脱敏显示。
判定：需要修订 M013。Key 输入框必须提供本地连接测试、脱敏显示和清除按钮。

### Round 016

Matrix: UX
视角：低分后想变好的用户。
攻击问题：用户看见 52 分但不知道下一次怎么提升。
当前观察：spec 有判词和修正台，但需要变成下一局任务。
判定：需要修订 M006。低分结算给出一个“补强委托”，把扣分项转成可执行下一局。

### Round 017

Matrix: UX
视角：想分享的人。
攻击问题：战报太长，分享出去没人看。
当前观察：spec 有摘要长度，但未定义分享卡。
判定：需要修订 M006/M032。生成可分享的短档案卡，但不包含敏感正文、Key、隐藏裁判信息。

### Round 018

Matrix: UX
视角：内容过载用户。
攻击问题：设定主张、声望、证据、冲突、图谱同时出现会过载。
当前观察：spec 有分层状态，但缺少默认信息层。
判定：需要修订 M001。默认只显示“本局发生了什么、你获得了什么、下一步做什么”；高级审档可展开。

### Round 019

Matrix: UX
视角：喜欢收集的用户。
攻击问题：复玩钩子是否足够明确。
当前观察：spec 提到结局收集和路线，但未定义收藏视图。
判定：需要修订 M006。agent 档案应展示结局图鉴、设定源流、阵营授权、伤痕收藏。

### Round 020

Matrix: UX
视角：流失边缘用户。
攻击问题：用户完成第一局后有没有强理由再开第二局。
当前观察：spec 有长期循环，但首局结算需要直接给下一局钩子。
判定：需要修订 M006。第一局必须生成至少一个接续委托、一个补证委托或一个找回委托。

### Round 021

Matrix: WORLD
视角：世界主理人。
攻击问题：用户主张会不会把共享设定误读成正史。
当前观察：spec 有生命周期，但前台展示需要硬边界。
判定：需要修订 M007。所有前台设定卡必须显示层级：正史、共享、传闻、争议、封存。

### Round 022

Matrix: WORLD
视角：设定洁癖读者。
攻击问题：高分用户生成的设定是否会稀释黑曜纪元气质。
当前观察：spec 有世界观契合评分，但没有气质守门清单。
判定：需要修订 M007。审档器需检查黑曜纪元气质：灾变、异化、代价、阵营关系、视觉基底、非万能结局。

### Round 023

Matrix: WORLD
视角：时间线维护者。
攻击问题：用户不断生成“裂灾后第十七年”的事件，时间线会不会拥挤和冲突。
当前观察：spec 有时间线校验，但没有拥挤度。
判定：需要修订 M008。时间线节点要有容量、冲突、拥挤提示；过密事件降为传闻或改时间范围。

### Round 024

Matrix: WORLD
视角：地图维护者。
攻击问题：腐林西缘被 200 条传闻堆满。
当前观察：spec 有聚合，但需加入密度节流。
判定：需要修订 M010。同地点同状态设定聚合为档案簇，并按证据质量排序。

### Round 025

Matrix: WORLD
视角：秘密设计者。
攻击问题：用户通过多次传闻拼出核心秘密。
当前观察：spec 有核心秘密不进前端，但未控制“拼图式泄露”。
判定：需要修订 M011。秘密相关线索要有揭露预算和章节闸门，不能因多轮普通任务累积出完整真相。

### Round 026

Matrix: WORLD
视角：阵营设定维护者。
攻击问题：玩家连续高分成为官方阵营顶层人物。
当前观察：spec 有章节和多人门槛，但顶端应更硬。
判定：需要修订 M009。官方阵营顶端不可由普通探索产生；最高只能到“外部关键关系人/议席候选”。

### Round 027

Matrix: WORLD
视角：自创阵营审核者。
攻击问题：玩家阵营通过多人互相引用快速成型。
当前观察：spec 有多人承认，但可能被小团体刷。
判定：需要修订 M009/M016。独立阵营升级要求跨探索者、跨委托类型、跨时间窗口的证据。

### Round 028

Matrix: WORLD
视角：生物库维护者。
攻击问题：agent 随手发明生物行为，破坏已有生物创作规范。
当前观察：spec 引用生物规范，但用户主张审核需要字段映射。

### Round 029

Matrix: WORLD
视角：能力系统设计者。

### Round 030

Matrix: WORLD
视角：叙事连续性维护者。

Matrix: WORLD

Matrix: WORLD

Matrix: SAFETY

攻击问题：无限创建新身份刷低质战报。
当前观察：spec 有组合限流，但需首局低价值保护。

Matrix: SAFETY
视角：内容审核。
