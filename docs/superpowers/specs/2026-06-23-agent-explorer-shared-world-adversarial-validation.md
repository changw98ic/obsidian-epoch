# 黑曜纪元 Agent 探索者共享大世界 100 轮串行对抗性验证

验证对象：`docs/superpowers/specs/2026-06-23-agent-explorer-shared-world-spec.md`

方法：按顺序提出 100 个失败场景。每轮只验证一个主要风险，记录攻击/失败假设、需要守住的系统性质、当前 spec 覆盖情况和结论。若发现缺口，标为“需修订”，并在后续 spec 修订中补齐。

## 结论摘要

- 通过且无需修订：40 轮。
- 通过但需实现时重点验证：2 轮。
- 提出需修订问题：58 轮。
- 修订落实：58 轮问题已归并补入 spec 第 29 节“对抗性验证后的硬化规则”。
- 阻断项：0。

需补充主题归并为：

1. 内容许可与公开战报使用权。
2. 申诉/复审机制。
3. 世界版本迁移与旧设定降级。
4. 评分器一致性和审档成本边界。
5. 身份重置刷首局收益的防线。
6. 手动介入模式，避免用户完全旁观。
7. 运营指标与验收仪表盘。
8. 数据删除、隐藏、审计之间的关系。

## 100 轮验证

应守性质：服务器永不接收、不代理、不存储用户大模型 API Key。
覆盖情况：spec 第 3、22、24、27 节明确服务器不接收 API Key。

## 修订清单

必须补充到 spec：

- 幂等结算与签名绑定。
- 可执行代价定义。
- 上下文包最小化与审计。
- 模板化刷分、同地点刷分、同类型刷分的收益递减。
- 内容发布状态、删除/隐藏/审计关系。
- 引用实体校验和 prompt 注入消毒。
- 客户端日志不记录 Key。
- 模型公平、调用预算、超时封存。
- 修正台防泄密。
- 文本长度和候选主张数量上限。
- 别名表、命名冲突、时间线校验、技能家族化。
- 外物消耗、损毁、绑定和稀有度。
- 图谱聚合与设定状态视觉区分。
- 匿名限流、恢复码安全、身份重置收益控制、签名防重放。
- 评分器版本化、文风中立、解释不泄露权重、人工审核队列。
- 世界版本迁移、设定降级、历史奖励封存。
- 设定升级必须重新审档。
- 结构化评价的举报/隐藏。
- 手动接管关键事件、agent 纪念/继承。
- 模型故障恢复、审档成本分层。
- 不可转让凭证、声望冲突矩阵、UGC 内容许可。
- MVP 运营指标和验收仪表盘。
