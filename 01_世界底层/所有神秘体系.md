# 所有神秘体系

《黑曜纪元》不存在一套供所有角色换皮使用的统一法力。诸天裂灾让多种彼此独立的力量源流同时进入现实；不同源流对力量来源、使用资格、成长方式、代价和失败的解释都可能互相矛盾，但它们造成的结果必须在同一个世界状态中接受裁定。

本页沿用旧文件名，实际登记范围包括神秘体系与能够处理神秘现象的工程体系。高科技不是魔法的别名，魔法也不是尚未解释的科技。

## 概念层级

```text
世界共同规则
└─ 力量体系 system
   └─ 传统 tradition
      └─ 分支 branch
         └─ 技法、仪式或工程 method
            └─ 角色在具体场景中的行动 action
```

- **力量体系**：力量从哪里来、谁能使用、如何成长、必须支付什么代价。
- **传统**：某个文明或组织对体系的稳定实践，例如符箓机械、学院奥术、世界树符文。
- **分支**：传统内部的专业方向，例如剑修、炼金、亡魂行政、星门工程。
- **作用领域**：力量正在干涉什么，例如灵魂、梦境、命运、空间或血肉。领域不是独立职业，同一领域可以被多套体系进入。
- **技法**：角色确实掌握并能在当前场景尝试的具体手段。

种族、势力、职业和力量体系不得互相等同。一个种族可以拥有多种亲和，一个势力可以教授多个传统，一个角色也可以学习外来分支；它们都必须保留各自资格、成本和风险。

## 共同不变量

1. 任何体系都不能仅凭叙述宣告成功。客户端模型只能描述意图、方法和投入，结果由服务端按 [[跨体系裁定规则]] 判定。
2. 任何超凡结果都必须有来源和代价。代价可以是资源、时间、身体负荷、精神污染、誓约义务、设备损耗、社会债务或未来风险，但不能省略。
3. 体系之间默认不能无损互换资源。灵炁不是以太，信仰不是电力，旧神低语不是普通数据。
4. 同一现象允许多种解释，但事实结果只有一份。例如亡者记忆可以被阴箓、葬歌、招魂术或人格恢复读取，最终写入的仍是同一个亡者状态。
5. 不可名状不等于不可裁定。未知体系可以隐藏机制，但仍必须记录影响范围、持续时间、代价、污染和可反制窗口。
6. 本相、科技、修行、魔法、神契与星外力量不存在永久的全局强弱排序；胜负取决于具体传统、准备、环境、资源、克制与使用者状态。
7. 混修不是免费叠加。跨体系使用必须经过兼容性、载体、知识、身份资格和污染检查。

## 跨源作用领域

七个体系可以进入相同领域，但不会因此变成同一体系。当前公共领域定义见 [[跨源神秘领域]]：

- 灵魂与死亡
- 梦境与心灵
- 命运与时间
- 星空、空间与量子
- 血肉、血脉与异化
- 生态、元素与环境

例如“处理亡者”只是目标领域：[[幽都鬼箓司]]依靠阴箓与冥权，[[墓歌族]]依靠歌声和记忆共振，[[乌鸦骨庭]]依靠战争命运与亡者见证，高科技则可能恢复人格快照。四者不能共享同一技能表，也不能自动获得相同法律地位。

## 实体如何绑定体系

每个可行动实体可以同时拥有以下信息：

| 绑定项 | 含义 |
| --- | --- |
| 先天亲和 | 血脉、身体结构、灵根、感官或硬件带来的天然入口，不等于已经掌握技能 |
| 已学传统 | 经过宗门、学院、氏族、企业或个人传承取得的稳定方法 |
| 技法熟练度 | 只对具体技法生效，不能用“我是法师”替代 |
| 身份许可 | 执照、宗门身份、神明认可、设备权限、数据库权限或禁术资格 |
| 当前资源 | 本次行动实际可消耗的灵炁、材料、算力、祭品、媒介、时间等 |
| 永久代价 | 已存在的污染、誓约、经脉损伤、债务、义体排异和人格缺损 |
| 社会认定 | 当地法律和文化如何看待其力量，与实际能力分开记录 |

种族只提供亲和与生理边界，势力提供传统、资源和许可，身份经历决定角色真正学会了什么。转生为某个种族不会自动获得该种族全部能力，加入某个门派也不会立即掌握其最高传承。

## 混修与跨体系学习

跨体系组合分为四种关系：

| 兼容级别 | 含义 | 默认后果 |
| --- | --- | --- |
| 共鸣 | 两套传统共享载体或能互相增益 | 可以组合，但仍分别结算资源与代价 |
| 可转译 | 能通过阵式、炼金、算法、祭仪等中介连接 | 需要转换设施、知识和额外损耗 |
| 冲突 | 两套体系会争夺身体、灵魂或现实解释权 | 同时使用提高失败、反噬或污染风险 |
| 禁忌 | 当前世界规则下没有安全共存方式 | 只能进行受控实验，不能作为普通角色常规能力 |

混修结果必须记录“谁是主体系、谁提供辅助、使用什么转换载体、产生什么新代价”。不能用“融合成功”一句话永久消除差异。

## 新体系的准入条件

模型、玩家或后续设定可以提出候选体系，但进入权威设定前必须回答：

1. 力量实际来自哪里，是否与现有体系重复。
2. 哪些身份能够获得入口，普通人如何接触。
3. 使用和成长分别消耗什么。
4. 失败会伤害谁、改变哪些世界状态。
5. 其他体系如何观测、误判、抵抗或利用它。
6. 它会形成哪些职业、组织、商品、法律和社会矛盾。
7. 至少提供一个不可被该体系轻易解决的问题。

未满足这些条件的新概念只能作为传闻、异常或未确认学说存在，不能由客户端模型直接写成角色能力。
