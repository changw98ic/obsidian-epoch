# 跨体系裁定规则

本规则负责把多套力量体系产生的行动落到同一个权威世界状态。叙事模型负责提出合理行动和描述已裁定结果，不拥有创造能力、免除代价、决定胜负或修改世界事实的权限。

## 权威边界

- 客户端或 Agent 可以声明：想做什么、准备用什么已知方法、愿意投入哪些资源、接受哪些风险。
- 服务端负责确认：角色是否会、是否有资格、资源是否存在、环境是否允许、目标如何抵抗、发生什么代价、结果如何持久化。
- 体系设定、隐藏机制、目标抗性和随机种子不能完整暴露给客户端模型。
- 任务的“及格、良好、优秀、惊世”属于任务结算层；单次超凡行动成功不能直接宣告整项任务完成。隐藏任务仍只由服务端持有和判定。

## 行动必须提交的信息

| 字段 | 说明 |
| --- | --- |
| `actor_id` | 实际行动者，不能用叙事主角称谓替代 |
| `system_id` | 本次行动采用的主体系 |
| `tradition_id` | 角色确实掌握的传统或传承 |
| `method_id` | 具体技法、仪式、设备或工程流程 |
| `domain_ids` | 本次要干涉的作用领域 |
| `target_refs` | 人物、物品、地点、关系或世界状态目标 |
| `declared_inputs` | 愿意消耗的资源、时间、材料、权限和协作者 |
| `intended_effect` | 希望造成的可验证结果，不是“发挥全部力量” |
| `risk_acceptance` | 是否接受受伤、污染、债务、暴露身份等可预见风险 |

缺少 `method_id` 时只能进行观察、询问或无体系的普通行动，不能由模型现场发明绝学补位。

## 服务端裁定流程

1. **身份验证**：检查种族生理、年龄、技能、传承、执照、誓约和设备权限。
2. **资源锁定**：锁定灵炁、材料、算力、祭品、生命状态、时间与协作者，防止重复消费。
3. **环境读取**：读取区域法则、天气、污染、基础设施、封锁、地形和当前世界时间。
4. **目标读取**：读取目标状态、体系来源、领域权限、抗性、已有防护和秘密状态。
5. **兼容判定**：确定是原生作用、共鸣、可转译、冲突还是禁忌，并加入转换损耗或风险。
6. **对抗结算**：综合掌握程度、投入、准备、环境、目标抵抗、反制、伤病与不稳定性得出结果。
7. **支付代价**：成功和失败都按实际过程结算消耗；失败不能自动退回已经烧毁或献出的资源。
8. **写入事实**：以类型化事件写入伤害、污染、关系、物品、区域、身份暴露、债务和持续效果。
9. **生成回执**：只把角色可知的证据交给叙事模型，再由模型写成故事。

## 结果等级

行动结果使用独立于任务评价的五档：

| 结果 | 含义 |
| --- | --- |
| 失败 | 目标效果没有成立，已发生的投入、暴露或反噬照常保留 |
| 有代价的部分成功 | 核心效果只完成一部分，或必须接受额外代价才能成立 |
| 成功 | 在申报范围内实现目标并支付正常代价 |
| 卓越成功 | 因充分准备、克制或协作取得额外但有依据的收益 |
| 失控 | 方法脱离预期并生成新的持续事件、污染或威胁，不等同于普通失败 |

“惊世”不属于这里。它只能由整局任务在满足服务端隐藏目标后给出。

## 跨体系关系

| 关系 | 裁定方式 |
| --- | --- |
| 原生 | 使用者以自己的体系直接作用于熟悉领域，按正常成本结算 |
| 共鸣 | 两种方法共享部分载体，各自支付成本后可以获得协同加成 |
| 可转译 | 必须存在翻译媒介，例如符箓芯片、炼金接口、神经仪器或祭仪阵列，并产生损耗 |
| 冲突 | 两套法则争夺同一载体或对象，增加反噬、污染、设备故障或身份撕裂风险 |
| 不透明 | 能观测结果但无法确认机制，只能采取封锁、采样、回避等有限行动 |
| 禁忌 | 没有已验证的安全接口；常规行动拒绝执行，只允许受控实验或剧情级事件 |

## 首批关键交互

| 交互 | 默认关系 | 能做什么 | 主要风险 |
| --- | --- | --- | --- |
| 裂灾本相 × 任一后天体系 | 共鸣或冲突 | 训练本相技法、安装辅助载体、以术式或修行扩大种族感官 | 外来方法争夺器官、记忆、灵魂或身份连续性 |
| 东方修行 × 西方奥术 | 可转译 | 用阵式映射术式、以真名辅助封印、比较经脉与以太回路 | 道心与契约同时反噬，双方误判对方资源 |
| 东方修行 × 旧日共鸣 | 冲突 | 斩除、镇压、隔离梦境或污染载体 | 把共鸣误作心魔，封印者被反向注视 |
| 西方奥术 × 原初神契 | 共鸣或冲突 | 契约可记录誓约，符号可承载部分神权 | 法律契约与神圣誓言争夺解释权 |
| 原初神契 × 理性工程 | 不透明或可转译 | 仪器观测神迹后果，工程设施稳定祭仪环境 | 把权柄误当能源，触发氏族战争或神罚 |
| 旧日共鸣 × 理性工程 | 不透明 | 采样信号、建立隔离、预测污染扩散 | 数据本身成为感染媒介，模型被非人逻辑改写 |
| 理性工程 × 赛博工业 | 共鸣 | 把实验成果制造成设备、药剂、义体与服务 | 专利垄断、偷工减料、身体产权和规模化事故 |
| 东方修行 × 赛博工业 | 可转译或冲突 | 符箓芯片、机械经脉、器官法器 | 经脉线路化、远程权限、供应链断裂 |
| 西方奥术 × 赛博工业 | 可转译 | 工业炼金、真名认证、批量仪式组件 | 契约被平台化，使用者承担隐蔽债务 |

这张表只规定默认关系，不预先决定胜负。具体传统可以改变局部关系，但必须把例外作为服务器规则登记。

## 裁定因素

服务端至少读取以下因素，不能让单一“战力值”覆盖全部差异：

- 角色对具体技法的掌握程度，而非笼统职业等级。
- 本次实际投入的资源、准备时间、设施和协作者。
- 身体需求、伤病、精神状态、污染、债务和誓约冲突。
- 地点是否适合该体系，是否存在灵脉、月相、网络、祭坛、实验设备等条件。
- 目标在相关领域的权限、抗性、伪装和反制。
- 体系兼容性、转换媒介质量及其剩余耐久。
- 行动规模、持续时间和对其他人物、经济、生态与政治造成的外部影响。

## 权威回执

每次超凡裁定至少产生：

- 使用了什么已登记方法。
- 哪些前置条件通过或失败。
- 实际消耗与新增代价。
- 目标状态发生了什么可持久化变化。
- 哪些变化被谁观察到。
- 是否生成后续事件、债务、污染、通缉、传说度或势力反应。
- 给叙事模型的可见事实，以及服务端保留的隐藏事实。

故事报告只能根据可见事实写起因、过程和结果，不得把判定字段逐条复述成事件日志。

## 禁止的叙事越权

- 因角色“意志坚定”而跳过资格、资源和对抗检查。
- 因模型熟悉某种设定而让角色突然掌握对应知识。
- 把未知现象自动归类为角色最熟悉的体系。
- 成功后不支付代价，失败后无条件退回投入。
- 用新造的神器、NPC或隐藏血脉解释本来无法完成的行动。
- 由客户端自行宣布隐藏目标、惊世评价或永久世界影响成立。
