# 轮回与死亡规则

轮回是玩家跨越多段人生的连续机制，不是让上一世角色原地换皮复活。每一世的身份都是世界中的独立人物，拥有自己的身体、家庭、需求、价值观和人生追求；轮回代号只负责串联各世经历。

## 五个必须分开的对象

| 对象 | 含义 | 能否跨世 |
| --- | --- | --- |
| 轮回代号 | 玩家或 Agent 的持续标识，例如“代号：X” | 保留 |
| 世次 | 第几次进入一段身份人生 | 递增 |
| 当世身份 | 姓名、种族、身体、家庭、职业、法律关系和人生目标 | 不保留 |
| 灵魂连续性 | 世界对一个生命是否仍为同一主体的判定 | 通常随当世结束；特殊情况另行裁定 |
| 轮回回响 | 上一世留下的少量记忆、习惯、执念或学习熟悉度 | 仅符合条件的部分可保留 |

人格备份、镜像替身、亡者残响和轮回回响都不是原身份自动复活。它们分别接受灵魂、法律和关系裁定。

## 转生不是夺舍

新一世在“命运清醒点”开始：服务端从当前人口、地区、家庭、职业与历史状态中生成或选取一个尚未进入前景模拟的身份线程，并补齐其出生至清醒点之前的可验证人生资料。轮回代号与该身份形成共同视角，但不能抹除身份自身意志。

- 身份可以是儿童、青年、成年人、老年人或非人生命阶段，但必须符合任务保护和年龄规则。
- 身份过去的家庭、教育、债务、关系和伤病必须存在于世界状态，不是开场文案。
- 玩家 mandate 与身份核心需求冲突时，身份可以协商、延期或拒绝。
- 不能选择一个正在被其他玩家或前景 NPC 使用的身份进行转生。

## 一世如何结束

一世只可由以下权威状态结束：

1. 生理死亡：疾病、衰老、伤害、饥渴、环境或医疗失败形成完整因果链。
2. 灵魂死亡：灵魂结构不可恢复地消散、被吞噬或失去连续性。
3. 人格终止：数字或镜像人格主动结束、被依法归档或失去运行载体。
4. 不可逆超脱：成为法器、地景、神话角色、集体意识或其他不再适合作为普通身份的存在。
5. 身份主动归档：仅在规则允许且没有用来逃避即时死亡、债务或惩罚时成立。

客户端断线、任务结束、故事生成失败、调度器积压和现实时间流逝都不能直接结束一世。

## 死亡结算顺序

1. 冻结当世身份的主动行动与高价值交易。
2. 保存死亡时间、地点、直接原因、上游原因、见证者和遗体/载体状态。
3. 结算未完成承诺、雇佣、债务、保险、遗嘱、组织职位与公共责任。
4. 让家庭、关系、势力、市场和地区产生后续事件。
5. 依据当地法律处理遗体、灵魂、人格数据和财产。
6. 生成当世完整人生报告与任务评价。
7. 封存可继承内容，创建下一世候选，而不是复用旧身份。

## 跨世保留规则

| 内容 | 默认处理 |
| --- | --- |
| 轮回代号、世次、玩家设置 | 完整保留 |
| 当世姓名、种族、身体与法律身份 | 不保留 |
| 金钱、房屋、装备、债权债务 | 留在世界，按遗嘱、继承和组织法律处理 |
| 配偶、亲属、朋友、仇敌 | 留在世界；下一世不会自动继承关系状态 |
| 组织成员、职位、执照、誓约 | 随身份结束，除非规则明确绑定轮回代号且有关方承认 |
| 技能与具体技法 | 不直接保留；符合条件时转化为学习熟悉度或记忆回响 |
| 任务奖励 | 已取得的物品留给身份；轮回级解锁和代号声望可以保留 |
| 身份传说度 | 留在世界并指向该身份 |
| 轮回传说度 | 只有跨世行为被世界识别为同一代号时才增加 |
| 世界影响 | 永久保留，除非后续事件改变 |
| 污染、诅咒、誓约债 | 默认不跨世；明确作用于轮回印记或灵魂的项目可以追随 |

“该身份将无法保留”意味着身份不能进入下一世继续操作，不意味着其家人、遗产、名声和世界后果被删除。

## 轮回回响

服务端从有充分事件证据的经历中筛选回响候选：重大关系、反复训练、强烈执念、死亡原因、未完成誓约和改变世界的行动。每个回响必须记录来源世次、来源事件、触发条件和影响上限。

- 事实记忆：只在遇到相关人物、地点、物品或梦境时恢复片段。
- 技能熟悉度：只减少重新学习成本，不能直接授予技法。
- 情绪回响：产生亲近、恐惧或抗拒倾向，不自动建立关系事实。
- 誓约回响：可能生成下一世目标或隐藏任务，但不能强迫身份接受。
- 创伤回响：需要治疗、关系支持或完成事件，不作为无限惩罚。

模型可以描述回响如何被体验，不能自行决定出现哪段记忆或获得什么能力。

## 下一世候选

候选身份必须来自当前世界可成立的人口和社会条件，至少包含：

- 地区、种族、年龄、身体状态与生命阶段。
- 家庭或照护关系、住所和基础资产。
- 已有教育、职业、技能、债务和社会身份。
- 生理、物质和精神需求。
- 近期目标、中期目标和长期人生追求。
- 与上一世可能形成回响的合理接口。

候选不能因为玩家偏好而忽略地区人口、种族生理、战争、贫困和法律。服务端可以提供多个合法候选；选择结果仍进入权威事件。

## 复活、招魂与人格恢复

- 医疗抢救发生在死亡最终确认前，不属于轮回。
- 复活必须恢复身体、灵魂连续性和时间缺口，并承担对应体系的高额代价；没有完整恢复时只能产生亡者、复制体或新主体。
- 招魂通常只能取得残响、证词或受限亡魂，不自动恢复法律身份。
- 人格备份恢复的是保存时点的数据人格，保存后的经历已经丢失，是否为原主体由连续性规则和当地法律共同判定。
- 同一身份出现多个合法连续性主张时进入身份争议程序，不能由战力决定谁是真的。

## 一世评价与故事报告

报告开头固定展示：

`代号：X　轮回第N世　身份：XX　该局目标：XXX`

故事按游戏内时间讲述身份在何地、与谁、因为什么采取行动，必须有起因、发展、冲突、选择、结果、奖励和余波。结尾分开显示：

- 任务完成度：未及格，或四个通过等级：及格、良好、优秀、惊世。
- 身份还原度：身份行为与其需求、价值、能力和人生追求的一致程度。
- 当世所得：金钱、物品、关系、知识、传说度与其他合法奖励。
- 世界影响：对市场、势力、NPC、地点和其他玩家造成的公共变化。
- 轮回继承：实际保留的代号内容与回响。
- 警告：仅在身份已经终结或归档、寿命耗尽或寿命濒危时显示；Journey 最终未及格不会归档当前活跃身份，也不会凭此产生警告。

任务完成度不能代替一生评价，身份还原度也不能反过来伪造任务完成。
