# 世界宪法

本页规定《黑曜纪元》中所有地区、体系、任务、人物和模型生成内容都不能绕过的最高规则。世界允许多种解释与文化，但同一时刻的事实、资源和因果只有一份权威状态。

## 规则优先级

发生冲突时按以下顺序裁定：

1. 已持久化的权威事件与当前投影。
2. 本页及其他已发布世界规则。
3. 已发布的地区、种族、势力和力量体系设定。
4. 具有来源的历史档案、新闻和人物记忆。
5. 尚未证实的传闻、模型推理和玩家猜测。

低优先级内容可以质疑高优先级事实，却不能直接覆盖它。修改权威设定必须发布新版本并保留旧事件的重放语义。

## 十项不变量

### 一、时间不倒流

世界只按 [[世界时间与历法]] 的权威时钟推进。预言、概率切换和时间异常可以改变未来分支或局部体验，不能删除已经结算的事件、复制已经消费的资源或让死者无代价恢复。

### 二、结果必须有原因

伤病、死亡、财富、关系、战争、名望、技能和污染的变化必须指向来源事件。模型不能用“命运如此”“隐藏血脉觉醒”或临时出现的神器补齐缺失因果。

### 三、物质与价值守恒

货币、商品、能源、土地资源和装备必须有来源、转移、消耗或损毁。声望、信任、知识与神秘资格不是普通商品，分别遵守自身规则。

### 四、行动受地点约束

人物同一时段只能位于一个可达地点。旅行需要路线、时间、费用和风险；远程行动需要网络、代理人、法术媒介或其他已登记接口。

### 五、人物拥有自身意志

转生身份和 NPC 都有身体需求、人生目标、关系与承诺。玩家或 Agent 提供行动目标，不构成对身份的绝对精神控制。高风险、永久关系、重大财产与违背核心价值的行动允许身份协商、延期或拒绝。

### 六、身份不能偷换

身体、法律身份、灵魂连续性、人格副本、镜像替身和轮回代号分别记录。拥有记忆不自动成为原身份，复制人格不自动继承婚姻、债务、职位或财产。

### 七、力量体系保持多源

所有超凡行动遵守 [[所有神秘体系]] 与 [[跨体系裁定规则]]。种族、势力和职业只提供可能入口，不能替代具体传统、技法、资源和代价。

### 八、知识具有传播路径

角色只能依据亲历、学习、调查、通信和可信来源行动。服务端秘密、他人私密状态和未公开世界事实不能因为客户端模型“知道设定”而成为角色知识。

### 九、社会会回应行动

公开伤害、交易、救援、污染、违约、研究和政治选择会通过法律、市场、关系、新闻与势力决策形成后果。任务结束不会冻结地区，也不会让未领取奖励之外的影响消失。

### 十、生成不等于成立

模型可以提出人物、任务路线、支线、对话、风俗和候选事件；服务端只接受符合对象、时间、地理、权限、资源和规则版本的部分。未通过验证的内容仍是候选或传闻。

## 固定规则与动态内容的边界

| 内容 | 权威设定必须固定 | 模型可动态生成 |
| --- | --- | --- |
| 时间 | 历法、事件顺序、行动耗时规则 | 天气描写、人物对时间的感受 |
| 地理 | 地点类型、邻接、路线、距离、辖区 | 临时摊位、路况事件、现场细节 |
| 种族 | 生理边界、需求、成长、繁衍与本相代价 | 个体外貌、家庭、性格、人生经历 |
| 势力 | 核心目标、治理、财政来源、领地和决策约束 | 当前计划、代表人物和具体行动方案 |
| 经济 | 货币、生产、库存、交易和损耗规则 | 价格、短缺、订单和商业机会 |
| 法律 | 权利、管辖、程序和违法类型 | 具体案件、证词、判决争议 |
| 力量 | 来源、资格、成本、能力边界和反制 | 合理的新技法候选与施展描述 |
| 任务 | 目标图、四档评价、奖励预算、隐藏任务权威 | 主支线路线、场景和叙事表达 |
| 故事 | 已发生事件、人物可知事实与实际结果 | 起因经过结果的文学化组织 |

## 权威对象的最低字段

任何进入运行世界的对象至少拥有：

- 稳定 ID、类型与规则版本。
- 创建来源、所在地区与当前状态。
- 可见范围和知识权限。
- 与其他对象的明确关系。
- 能被改变的字段及其合法事件类型。
- 退役、死亡、销毁、归档或失效条件。

只有名称和一段气氛描述的节点不能成为任务目标、奖励、NPC、势力或可交易资产。

## 设定变更流程

新设定先作为 `candidate`，通过重复检查、因果检查、地理检查、资源检查和现有事件兼容检查后发布为 `canonical`。存在争议的内容保留 `disputed` 状态；叙事可以呈现争议，但服务器不能随机选择其中一版当作事实。
