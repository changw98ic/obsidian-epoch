# 裂灾血脉与本相

裂灾血脉与本相体系描述已经稳定写入智慧种族身体、灵魂、感官或群体记忆的生得异能。它们最初可能来自污染、工程、神血或未知灾变，但经过世代繁衍后已经能够脱离原始来源自行延续，成为该族群真实的生命结构。

这不是收纳零散能力的万能分类。每个种族必须拥有自己的 `lineage_rule_id`、器官或灵魂载体、成长条件和代价；两个种族同属本体系，不代表能够互相学习或共享资源。

## 与其他体系的边界

| 情况 | 应归入 |
| --- | --- |
| 能力依靠当前仍在连接的旧神、外神、信号或污染源 | [[克苏鲁眷族|旧日与星外共鸣体系]] |
| 能力依靠神祇权柄、誓约、氏族见证或世界树归属 | [[北欧原始神系|原初神契体系]] |
| 能力必须后天修炼、学习术式或取得工程设备 | 对应修行、奥术、理性工程或赛博工业体系 |
| 能力已成为可繁衍、自维持且具有稳定生理或灵魂代价的族群本相 | 裂灾血脉与本相体系 |
| 只是普通生理适应，没有超凡世界效果 | 普通种族特征，不进入力量裁定 |

## 力量来源

- 裂灾后稳定遗传的器官、血脉、灵魂结构、感官和集体记忆。
- 维持本相所需的食物、光线、温度、盐分、电流、梦境、名字、情绪或环境。
- 成年礼、族群训练、祖先记忆和身体成熟形成的控制能力。
- 个体与其镜像、备份、双生体、族群网络或出生地之间的持续联系。

## 取得资格与成长

生得异能通常只能通过出生、稳定转化、继承或经过权威裁定的移植取得。知道某族能力的原理不能让外族直接使用。成长来自身体成熟、控制训练、族群仪式、环境适应和对本相代价的管理，不使用统一境界。

转生身份只获得其年龄和生命阶段真实具备的能力。幼年个体、失去关键器官者、与族群环境断联者或未完成成年礼者，可能只有感知而没有主动技法。

## 主要失败

- 强行超出生命阶段或身体承载上限，造成器官、人格或灵魂损伤。
- 离开适宜环境后仍按满状态使用，导致能力失真或身体衰竭。
- 外来改造与本相争夺同一器官、记忆、神经或身份连续性。
- 把族群习惯误当作能力代价，或反过来把真实生理需求当成纯文化选择。
- 试图复制能力却只复制外观，没有复制维持其存在的生命闭环。

## 可观测与反制

本相通常通过生理检查、血脉记录、行为证据、灵魂结构或对应环境被识别。反制可以针对载体、环境、节律和代价，但不能因为掌握种族弱点就自动控制该种族。医疗、压制与迫害必须在世界法律和关系系统中分别记录。

## 社会形态

生得异能直接影响饮食、住房、教育、医疗、劳动、婚姻、生育、迁徙和法律身份。城市必须提供不同种族的基础服务；企业和势力也可能把本相当作劳动力、能源、武器或专利来源，由此形成歧视、保护、自治与身体产权冲突。
