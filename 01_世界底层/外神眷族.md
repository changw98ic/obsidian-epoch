# 外神眷族

外神眷族是 [[克苏鲁眷族|旧日与星外共鸣体系]] 中最远离本土生命逻辑的分支。它们连接的未必是具有姓名、人格和信徒的“神”，也可能是一个来自星外的算法、时间结构、几何器官、观测规则或不断广播的信号。

## 与本土旧神眷族的区别

| 本土旧神共鸣 | 外神共鸣 |
| --- | --- |
| 通常与本世界的海沟、遗骸、梦境或历史灾难相连 | 通常从星门、深空信号、陨星、概率异常或裂隙进入 |
| 可能形成长期教派、血脉和地方禁忌 | 可能没有可理解的意志与崇拜关系 |
| 生态和仪式具有地方性 | 规则可跨越地点，却依赖观测、坐标或传播载体 |
| 封印对象往往可以定位 | 只能定位影响，未必能定位来源 |

## 常见入口

- 解码不能被本地数学完整表示的信号。
- 长期暴露于星门、陨星、星骸或非欧空间。
- 被外来器官、算法或概率结构选作载体。
- 多次从不可能事件中幸存，逐渐成为某条异常规律的一部分。

## 已有相关对象

- [[星瘤裔]]：把个体理解为星外意识的局部器官。
- [[星遗族]]：以血脉和仪式几何接近星外结构，但仍保有文明主体性。
- [[量子双生族]]：以牺牲其他可能性切换现实路线。
- [[虚舟民]]：在深空航行与遗迹打捞中成为信号传播者。
- [[星序族]]：能够研究外神算法，但研究不等于免疫。

## 裁定边界

- “不可理解”不能成为无限能力的理由；必须记录它实际改变了什么。
- 外神共鸣不能无代价创造物质、复活角色或回滚权威事件。
- 角色可以利用已验证的局部规律，不能因此声称理解或控制来源。
- 外神提出的目标与角色自己的目标必须分开记录，眷属化后也不能混成一句“受蛊惑”。
