# 势力低级生物

势力低级生物是各组织驯养、制造、寄生、召唤或长期共生出的基层生命单位。它们不具备完整文明主体性，通常承担侦察、清道、看守、采集、污染扩散、仪式耗材与战场消耗品等功能。

## 设计约束
- 遵循 [[生物创作规范]] 和 [[异化生物创作规范]]；本页只补充势力低级生物的局部限制。
- 威胁评级以 D / C 为主；单体可被普通武装小队处理，群体或主场环境中才危险升级。
- 每个单位必须能反映所属势力的核心能力、代价与基底气质。
- 不做首领、不做神兽、不做唯一存在；它们应该可以批量出现，用来填充遭遇、生态和势力日常。
- 保持与[[孢雾巡猎者]]同级：有明确外观、行为、能力、弱点和可采集资源，但不需要图片。
- 每批新建单位必须能看出它为什么会被该势力制造、驯养、寄生、召唤或容忍。

## 与孢雾巡猎者的对齐
[[孢雾巡猎者]]代表自然异化生态中的基层掠食者；本谱系则代表“组织化异化生态”的基层单位。两者可以互为参照：
- 孢雾巡猎者更野生，靠孢雾、群猎和栖息地优势生存。
- 势力低级生物更工具化，靠所属组织的仪式、纪律、饲养方式或技术系统维持稳定。
- 二者都可以作为剧情入口：战斗遭遇、资源采集、污染线索、势力痕迹与后续 Boss 的前兆。
