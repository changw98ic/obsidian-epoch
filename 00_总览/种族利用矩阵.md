# 种族利用矩阵

本矩阵用于把现有种族转化为生物、生态、材料、精英、头目和世界级生命的创作来源。以后创建任何批次生物时，优先从本矩阵选择 1 到 3 个种族作为母题，再结合地点、势力、威胁层级和 [[生物创作规范]] 生成。

## 使用规则
- 每个新生物至少说明它与哪个种族、生态或势力有关：共生、寄生、驯养、制造、崇拜、猎食、材料来源、失控变种或恐惧对象。
- 同一批生物可以共用一个种族母题，但必须拉开外观倾向、生物倾向和叙事层级。
- 种族不是道德模板。种族本身偏善、偏恶、秩序或混乱，都不能强制决定其衍生生物的倾向。
- 精英、头目、首领和世界级生命也必须使用本矩阵，不只低级生物使用。

## 快速公式
`种族母题 + 地点/势力 + 层级 + 外观倾向 + 生物倾向 = 可落地生物`

示例：
- [[管巢族]] + [[城市管道]] + E级 + 可爱/中庸 + 秩序中立 = 会画回程路标的管露蜗类生物。
- [[白械天使]] + 轨道审判站 + 首领 + 神圣/诡异 + 秩序邪恶 = 无差别净化城市的失律光环母机。
- [[肉件族]] + 黑诊所 + 头目 + 恶心/炫酷 + 混乱中立 = 出租器官、买卖记忆腺体的活体仓主。
