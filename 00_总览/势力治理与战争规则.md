# 势力治理与战争规则

势力不是一个名称、倾向和无限兵力。任何可行动势力都必须拥有成员、治理结构、财政、领地或设施、资源、目标、内部派别与决策程序。

## 势力最低字段

- 稳定组织 ID、成立来源与合法状态。
- 总部、控制地点、影响范围与可达路线。
- 成员规模、职业构成、招募和退出规则。
- 权力结构、任期或继承、监督和内部派别。
- 金库、库存、收入、固定支出、债务和行动预算。
- 公开目标、隐藏目标、底线和禁止手段。
- 外交关系、条约、争端与战争状态。
- 可提供的工作、教育、许可、公共服务和任务奖励。

主要势力的第一版制度见 [[势力制度总表]]。

## 决策周期

每个势力按世界 tick 读取：

1. 生存与财政压力。
2. 领地和成员安全。
3. 当前公开目标与派别诉求。
4. 已有承诺、条约、战争与任务结果。
5. 可用金钱、物资、人员、情报和行动预算。
6. 若干合法行动候选及其成本、风险和预期效果。

服务端根据规则和种子选择行动；模型可以提出候选与理由，不能直接让势力宣战、结盟、破产或完成建设。

## 外交状态

| 状态 | 含义 |
| --- | --- |
| 未接触 | 缺少稳定沟通或相互认知 |
| 中立 | 无有效合作或敌对承诺 |
| 往来 | 存在贸易、教育、通行或信息协议 |
| 合作 | 对具体目标共同投入资源 |
| 同盟 | 有正式互助与退出条款 |
| 竞争 | 争夺资源、人才、市场或声誉，但未进入武装冲突 |
| 敌对 | 允许制裁、封锁、谍报或有限暴力 |
| 战争 | 已满足开战程序并存在战役与补给 |
| 停战 | 暂停敌对行动，争端尚未解决 |

关系由事件与条约改变，不使用单一好感值替代。

## 建设与财政

- 势力建设需要地点权利、设计、材料、劳动力、时间和维护预算。
- 财政收入可以来自税费、会费、生产、服务、贸易、捐赠、战利品或借款，必须分别记账。
- 教育、医疗、军队、研究、宗教和行政都会产生持续支出。
- 没有预算时势力只能缩减项目、欠款、征税、借贷、出售资产或寻求合作。
- 玩家贡献只能减少真实缺口，不能一件物品瞬间完成整座要塞。

## 战争成立条件

发动战争至少需要：

- 明确敌对对象与政治目标。
- 可到达的战区和合法或实际动员路径。
- 指挥结构、兵员、武器、运输、食物、医疗和补给预算。
- 对内部支持、外交后果和平民风险的评估。
- 服务端生成的战争状态事件。

故事模型不能因一次争吵直接宣告全面战争。

## 战役阶段

动员 → 集结 → 侦察/外交最后窗口 → 补给运输 → 战斗/围困/破坏 → 伤亡与撤退 → 控制或目标结算 → 停战/继续。

每次推进都消耗世界时间和资源。缺粮、断路、疾病、士气、天气和内部反对可以降低强度或迫使撤退。

## 战争影响

- 地区控制、税费、路线安全与公共服务。
- 平民死亡、难民、失业、物价与疾病。
- 设施损毁、资源产量、生态和长期污染。
- 关系、宣传、传说度与其他势力介入。
- 玩家任务、市场和下一世候选身份。

战争不会直接删除玩家私人高价值资产；征用、损毁和没收必须经过具体事件、权限和补救规则。

## 阵营选择

加入阵营需要了解公开目标、义务、退出代价和敌对关系。不同阵营提供不同工作、学习、资源和主线，但身份可以保持中立、退出、叛逃或建立第三路线，只要世界条件允许。

支线可以通过真实效果改变主线，例如取得证据、修复路线、赢得社区支持或解决财政缺口。解锁不是点击奖励，而是服务器状态改变。
