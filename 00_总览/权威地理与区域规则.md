# 权威地理与区域规则

本页区分真实可旅行地点与知识图谱概念。种族、力量体系、冲突轴、环境危害和数组标签都不是地理区域；只有拥有稳定空间类型、父级、坐标关系、辖区和路线的对象才能进入服务端位置系统。

## 空间类型

| 类型 | 含义 | 是否可作为人物当前位置 |
| --- | --- | --- |
| `world_layer` | 轨道、地表、地下、深海、异维等空间层 | 否 |
| `macro_region` | 大片连续地理区域 | 可以，但通常应进一步定位 |
| `settlement` | 城市、港口、哨站、部族聚居地 | 是 |
| `district` | 城市街区、矿井分区、学院区 | 是 |
| `site` | 实验室、剧场、神庙、资源点 | 是 |
| `route` | 两个空间对象间可通行的连接 | 旅行中状态 |
| `mobile_site` | 商队、舰船、移动营地 | 是，必须绑定当前路线或区域 |
| `anomaly` | 具有空间影响的异常 | 只有服务端确认入口后可以进入 |
| `hazard` | 工业废液、孢雾、辐射等环境状态 | 否，附着于地点 |

## 镜面城内部基准

- 普通街区步行到数据巷：20—45 分钟。
- 数据巷到全息剧场：30 分钟公共轨道。
- 地表入口到城市管道指定维修段：15—90 分钟，取决于权限与积水。
- 市中心到量子实验室：45 分钟公共轨道，加 20—60 分钟安检。
- 市中心到概率温室：70 分钟货客混行线。

“任务已经开始”不等于瞬间抵达。准备、通勤、安检、等待和返程都占用世界时间。

## 边界与管辖

- 地理归属、行政管辖和势力控制分开记录，同一地点可能存在争议控制。
- 改变地区控制必须来自战争、条约、选举、购买或其他权威事件。
- 地区内的具体建筑不能凭名称继承整个地区的资源与法律权限。
- 路线关闭时，模型只能选择已存在替代路线、等待、协商或放弃，不能临时发明传送门。
