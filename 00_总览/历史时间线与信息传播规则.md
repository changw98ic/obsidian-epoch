# 历史时间线与信息传播规则

世界历史由已确认事件、来源有限的档案和相互冲突的解释共同构成。角色知道什么取决于其经历和信息渠道，不等于客户端模型拥有的全部设定。

## 第一版大历史

| 黑曜历 | 时期 | 已确认事实 | 仍有争议的解释 |
| --- | --- | --- | --- |
| 纪元前 | 裂灾前世界 | 多个文明、神系与技术体系原本并不处于同一现实层 | 是否存在一个原初世界，或本来就是多个世界 |
| 0—27 年 | 诸天裂灾期 | 维度、神系、梦境与星外逻辑大规模重叠；人口与地理重创 | 裂灾是事故、战争、苏醒、天道破裂还是人为实验 |
| 28—119 年 | 幸存与定居期 | 第一批稳定聚居地、封印、灵脉、轨道残站和跨族社区形成 | 哪些种族在裂灾前已存在 |
| 120—188 年 | 六系冲突期 | 修行、奥术、神契、旧日、高科技与工业势力为解释权和资源多次战争 | 多场战争的挑起者与真实伤亡 |
| 189—304 年 | 工业开采期 | 神尸矿、异常能源、义体、星门和记忆产业快速扩张 | 工业繁荣是否延缓或加剧下一次裂灾 |
| 305—381 年 | 轨道整合期 | 轨道城恢复、跨区结算和主干交通标准逐步建立 | 轨道机构是否隐瞒了外神信号事故 |
| 382—411 年 | 条约与暗战期 | 多数主城建立最低主体权利和污染通报条约，公开大战减少 | 秘密实验、代理战争和身份替换案件规模 |
| 412 年 | 当前 | 世界处于脆弱互联状态，贸易、战争、轮回和异常继续推进 | 下一次大裂灾是否已经开始 |

这条时间线只规定时代骨架。具体城市、家族和角色历史必须有来源事件，模型不能把时代名称当成万能背景。

## 信息状态

| 状态 | 含义 | 能否作为服务器判定事实 |
| --- | --- | --- |
| `canonical` | 已由权威事件或发布设定确认 | 可以 |
| `recorded` | 有档案记录，但档案可能不完整或有立场 | 只能证明“档案如此记载” |
| `reported` | 新闻、证词或组织通报 | 需要交叉验证 |
| `rumor` | 有传播路径但无充分证据 | 不可以 |
| `secret` | 已确认但只对有限主体可见 | 服务端可用，未授权角色不可知 |
| `disputed` | 多份证据冲突，尚无最终裁定 | 只能作为争议事实 |
| `false` | 已被证伪但可能仍有人相信 | 不能作为世界事实，可影响相信者行动 |

## 知识来源

人物知识必须来自：亲历、可靠感官、训练、档案访问、他人告知、新闻、仪器、神秘观测或合法推断。每条重要知识记录来源、取得时间、可信度、可分享范围和是否过期。

- 读心只能读取目标当时可访问的心理内容，不保证真实。
- 预言提供带条件的未来线索，不是已经发生的事实。
- 仪器读数证明测得的现象，不自动证明理论解释。
- 亡者证词、人格备份和轮回回响都有时间与连续性缺口。
- 势力宣传可以是真的、选择性披露或伪造，分别处理。

## 传播速度

| 渠道 | 常见速度 | 限制 |
| --- | --- | --- |
| 当面、纸件、管道震动 | 同地点分钟至小时 | 距离、识字、截获 |
| 城市网络 | 秒至分钟 | 权限、断网、信息污染 |
| 城际通信 | 分钟至小时 | 中继、审查、费用 |
| 商队与邮路 | 数小时至数日 | 路线、天气、战争 |
| 轨道中继 | 分钟至小时 | 轨道窗口、加密、控制权 |
| 梦境、神谕、预言 | 不稳定 | 解释、污染、无法证明送达对象 |

新闻与传说度只能影响实际收到或接触传播的人群。一次行动不会瞬间让全世界知道。

## 新闻、谣言与传说度

- 公共事件先生成可验证摘要、地点、时间、来源和可见证据。
- 媒体、势力和人物根据立场形成不同报道。
- 谣言必须记录起点、传播群体、变形和反驳。
- `legend` 根据覆盖人口、可信度、事件重要性和身份可归因程度变化。
- 匿名行动可以改变世界，却不一定增加身份传说度。
- 揭穿虚假英雄事迹会降低或反转传说度，但已造成的社会后果仍需新事件纠正。

## RAG、设定库与数据库

- RAG 用于检索世界设定、历史档案和角色有权访问的资料。
- 数据库/事件账本保存当前时间、位置、库存、关系、人口、战争、任务和其他可结算状态。
- RAG 检索结果不能覆盖数据库事实。
- 动态事实写入数据库后，可以生成带来源的新闻或档案供 RAG 索引。
- 模型生成的总结只是一种读模型，不是新的权威事件。

## 历史扩展规则

新增重大历史事件必须说明时间、地点、参与者、原因、经过、结果、伤亡、资源变化、政治后果、留下的证据和仍有争议的部分。只有一句“发生过大战”的条目不能作为当前仇恨或领土依据。
