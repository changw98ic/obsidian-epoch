# 法律与公共服务规则

世界没有覆盖所有地区的单一政府，但存在跨文明承认的最低权利和管辖规则。地方可以更严格或提供更多权利，不能以习俗为由把智慧生命降为普通商品。

## 管辖层级

1. 地点即时安全规则：实验室、矿井、舰船和神庙可制定现场程序。
2. 城市或聚居地法律：处理居民、财产、商业、公共服务和普通犯罪。
3. 势力内部规则：约束成员、传承、职位与组织资产。
4. 区域条约：处理旅行、贸易、战争、引渡、星门和污染。
5. 世界最低权利：在承认智慧主体的地区具有优先保护效力。

同一事件可能同时触发多个层级。组织纪律不能免除城市犯罪责任，城市许可也不能授权破坏跨区封印。

## 智慧主体的最低权利

- 身体、灵魂、人格和记忆不受未经同意的占有与改写。
- 获得饮水、紧急医疗、危险告知和基本申诉渠道。
- 不因种族、本相、身体形态、出生、贫困或无超凡能力被自动认定有罪。
- 儿童、失能者、受污染者和人格不稳定者获得适当照护与代理，而不是自动失去主体地位。
- 复制体、镜像体、数字人格和亡者主体可以申请连续性审查，不能仅凭载体类型否认。
- 战俘、债务人、雇员和组织成员不能被当作无权退出的永久财产。

## 身体、器官与义体

- 医疗、强化、移植和实验分别记录，必须说明目的、风险、可逆性与数据用途。
- 紧急救命可以在无法取得同意时进行最低必要处置，事后必须审查。
- 器官和血液交易需要来源、同意、数量、保存与追踪记录。
- 义体维护合同不能授权远程伤害使用者；远程停用只允许处理明确的公共危险并接受审查。
- 身体改造造成的新意识或多余灵魂必须进行主体评估，不能当作医疗废物销毁。

## 记忆、梦境与人格

- 读取、出售、复制或修改私人记忆需要明确范围和期限。
- 梦境进入、情绪操纵、广告植入和人格训练属于精神干预。
- 备份服务必须标记保存时间、缺失区间、访问者和删除策略。
- 真名、灵魂签名、轮回回响和身份验证数据属于高敏感信息。
- 公开利益不能成为无限监控理由；调查必须针对具体事件和权限。

## 婚姻、伴侣与家庭

- 伴侣关系需要双方为规则允许的主体并持续同意。
- 亲密动机、好感或任务目标不能自动生成恋人、配偶或生育结果。
- 不同种族可以采用婚姻、伴侣契约、氏族接纳、双生绑定、人格共同体等家庭形式。
- 财产、照护、监护、遗产和子女/新成员责任必须单独约定。
- 拒绝追求、结束关系和不生育都是合法结果；暴力、胁迫和记忆操纵不因亲密关系免责。

## 死亡与继承

- 死亡确认必须区分身体死亡、灵魂死亡、人格终止和不可逆超脱。
- 遗体、灵魂、人格备份和轮回回响分别处理。
- 遗嘱只能处分身份合法拥有的财产和许可，不能处分他人的灵魂、记忆或自由。
- 未立遗嘱时按当地家庭、债务和组织规则处理；争议资产进入托管。
- 新一世不自动成为上一世继承人，也不自动承担其私人债务。

## 违法类型

| 类别 | 例子 |
| --- | --- |
| 人身与灵魂侵害 | 伤害、绑架、强制改造、吞魂、非法复活 |
| 身份与记忆犯罪 | 冒名、镜像替换、真名盗用、记忆篡改、人格劫持 |
| 财产与商业犯罪 | 盗窃、诈骗、合同欺诈、器官黑市、伪造货封 |
| 环境与异常犯罪 | 非法排污、破坏封印、传播污染、无证星门实验 |
| 公职与组织犯罪 | 贪污、滥权、伪造许可、隐瞒灾害、非法征兵 |
| 战争犯罪 | 攻击平民、断绝最低生存服务、强制眷属化、使用失控污染武器 |

## 程序

调查至少区分：线索、证词、仪器结果、神秘观测、推断与已确认事实。单一预言、读心、真名审讯或算法评分不能直接定罪。

通常流程为：报案或发现 → 管辖确认 → 证据保全 → 临时安全措施 → 听证/审判 → 补救与处罚 → 公开或受限记录。紧急状态允许先隔离危险，但不能无限期跳过复核。

## 最低公共服务

人口达到稳定聚居规模的地区必须定义：

- 饮水、食物配给与卫生设施。
- 紧急住所、消防、污染隔离和灾害疏散。
- 普通医疗、种族专科、精神/梦境与义体维修转诊。
- 基础教育、语言支持和成年资格途径。
- 死亡登记、遗体/灵魂处理与失踪人口服务。
- 纠纷调解、公共档案、道路和基础通信。

服务不足会形成疾病、迁徙、犯罪、抗议和势力支持变化，不能只作为背景描写。
