# 世界运行规则索引

本页是黑曜纪元连续世界的规则入口。世界观描述“有什么”，运行规则规定“它如何变化”，数据库保存“现在已经变成什么”。模型只能在这些边界内推理角色与叙事。

## 权威顺序

1. 已提交的服务端事件、投影和结算证据。
2. [[世界宪法]] 与下列版本化运行规则。
3. 已发布的种族、势力、地点、物品和力量体系设定。
4. 可访问档案、新闻、传闻和角色认知。
5. 模型提议；未被服务端接受前不构成事实。

## 底层时间与连续性

- [[世界宪法]]：不变量、事实优先级与模型边界。
- [[世界时间与历法]]：游戏内时间、历法、季节和推进。
- [[天气灾害与世界事件规则]]：地区天气、灾害生命周期、传播、响应和恢复。
- [[轮回与死亡规则]]：代号、世次、身份、灵魂、死亡与跨世保留。
- [[身份人生与需求规则]]：身体、物质、关系、精神、日程和人生追求。

## 空间、人口与社会

- [[权威地理与区域规则]]：空间层、地区、聚落、地点、路线与管辖。
- [[生态人口与生命规则]]：人口账本、出生、死亡、生态、疾病和承载力。
- [[种族生命参数总表]]：三十个智慧种族的生命与社会基线。
- [[健康医疗与污染规则]]：伤病、医疗容量、污染、残障和死亡接口。
- [[教育职业与社会流动规则]]：岗位、学习、资格、失业、晋升与转行。
- [[文化与日常生活规则]]：语言、饮食、衣住、教育、家庭、信仰与丧葬。
- [[法律与公共服务规则]]：主体权、身体/人格/记忆权、犯罪、程序与服务。

## 经济、势力与历史

- [[世界经济与资源规则]]：货币、库存、生产、贸易、价格、工资与守恒。
- [[物品制造与技术研究规则]]：物品来源、所有权、配方、维修、科研和技术解锁。
- [[势力治理与战争规则]]：财政、成员、外交、阵营、战争、占领与战后影响。
- [[势力制度总表]]：正式势力的治理、收入、招募、目标与底线。
- [[历史时间线与信息传播规则]]：历史层、证据状态、新闻、传闻与 RAG 边界。

## 力量与异常

- [[所有神秘体系]]：七套独立力量体系与六类跨源领域。
- [[裂灾血脉与本相]]：种族血脉、本相与个体能力边界。
- [[种族与体系映射]]：三十种族、正式势力与体系亲和。
- [[跨源神秘领域]]：同一领域在不同体系下的实现。
- [[跨体系裁定规则]]：不同系统作用于同一目标时的服务端裁定。

## 任务、叙事与玩家影响

- [[任务机会与服务端裁定规则]]：世界机会、任务类型、分支、四档、隐藏目标和奖励。
- [[人生故事报告规则]]：从事件重建完整一世故事，日志与玩家报告分离。
- [[镜面城]]：首个非固定 NPC、可分叉主线、经济法律生活闭环的可玩纵切。

## 机器可读权威资产

- `00_总览/canonical-world-atlas.json`：空间层、地点、父子关系与永久路线。
- `00_总览/world-map-data.json`：由 Markdown 生成的展示图数据，不是运行时世界状态。
- 运行时事件数据库：角色、库存、关系、任务、经济和世界当前态的唯一权威来源。
- RAG：检索设定、档案和角色可知信息，不承担余额、位置、死亡、完成度等权威状态。

## 完整性的边界

规则已经定义生成和裁定边界，不要求预先写死所有人物、店铺、商品、任务与历史细节。以下内容应在运行时生成并持久化，而不是继续堆静态名单：NPC 姓名与家庭、当前价格、每日库存、天气、具体任务路线、隐藏目标、政治投票、战争战线和每一世故事。

新增设定必须使用 `_templates` 中相应模板，声明稳定 ID、权威状态、输入输出、持续影响和不可由模型决定的字段。
