# 合并建议

| 当前概念 | 建议处理 | 理由 |
| --- | --- | --- |
| 潮裔 / 渊眠族 | 渊眠族作为深海母族，潮裔作为浅海或人类混血分支。 | 避免两个深海血脉种族功能重复。 |
| 瞳民 / 裂瞳民 | 裂瞳民作为古老眷族，瞳民作为城市化或被学院收编的分支。 | 都承担真相目击和预言污染功能。 |
| 肉圣族 / 肉件族 / 丹鼎肉仙门 | 肉圣族为血肉宗教种族，肉件族为工业黑市族群，丹鼎肉仙门为东方修炼组织。 | 同属血肉改造，但社会位置不同。 |
| 星遗族 / 星序族 / 星瘤裔 | 星序族为高科技上层，星遗族为古老陨星血脉，星瘤裔为污染眷族。 | 同为星外逻辑，但文明层级不同。 |
| 墓歌族 / 幽都鬼箓司 / 乌鸦骨庭 | 三者共同构成亡者秩序三极。 | 分别代表亡者数据库、东方阴司、北欧命运见证。 |
